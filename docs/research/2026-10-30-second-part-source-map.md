## 证据与编写原则

优先阅读原始材料，以公开技术文档交叉核对稳定机制。作者观点、来源记载、教材推理、教学设定和实际运行分别标注。阅读资料不等于复现实验；手算例题不等于真实模型测评。正文采用原创解释与原创教学数据，图中结构由教材重新组织。固定版本供复查，最新界面和行为可能不同。

逐章证据条目、取舍与自审结果随正文完成补入本文件和配套评审记录。

## CH04 证据与取舍

- 参数、损失：Google ML Crash Course 的 Loss 与 Fundamentals 条目；以原创线性例题解释，不搬用上游数值。
- 训练/验证/测试与过拟合：Google 的 Dividing datasets、Overfitting；正文区分零训练误差、独立检查与情境变化，没有把 F 的偏差直接判为过拟合。
- 训练数据与任务匹配：Chip Huyen 配套摘要第 2、8 章；强调质量、覆盖和数量，未引入规模崇拜。
- AIInfra：固定版 00Summary/04TrainingStack.md 第 1、5、6 节已读；只采用可核对的流程角色。对其中未找到直接原始依据的 GPT-5 训练规模、性能增益及绝对安全指标予以排除，不由标题或作者声誉推定事实。
- 自监督与使用：Hugging Face Transformers v4.46.0 的 Causal language modeling；明确教学模型不是大模型训练复现。
- 2026-10-30：CH04 正文、独立实践、规格及新图 AG-04-03 已形成；全站检查通过，视觉复核及跨章终审随本轮继续进行。

## CH05 证据与取舍

- Hugging Face Tokenizers 与 Generation with LLMs（v4.44.0）：词元、逐步生成与采样。正文只写稳定机制，不依赖最新 API 操作。
- 李博杰第 2 章：阅读上下文构成、消息角色与工具返回的相关节；区分材料、指令与环境，不泛化为所有服务的固定 API 结构。
- Chip Huyen 第 2—6 章摘要：数据/采样、评价、提示与 RAG；不把其对某些方法的概括当作普遍保证。
- Neo Lee 第 20—23 页：用于问题意识与具体任务观察，旧演示题不构成当前模型能力排行榜。
- AIInfra 固定版 README 与训练/推理专题：只取定位、更新说明和目录条目，形成 A1/A2/B1/B2；不复制章节中缺乏独立核验的定量断言。
- 编写者原创：候选甲乙为证据辨析情境，不是 API 调用；明确纸面学习与真实生成的不同证据。
