# ADR-0002：前三章围绕同一份导览逐步学习

日期：2026-10-29。状态：本轮编辑采用，待维护者评审。上游：课程宪法、course.json 中 CH01—CH03 / M01—M03。

## 问题

逐章完成的 0.2.0 稿已具备情境、图件、任务与反馈，但连读时存在四处断点：默认新手能编辑 Markdown；第一章接入条件未实测；第二章术语和记录项集中；第三章模板容易被理解为整站授权审查。三个材料包和通用模板的入口也容易使人重复建站。

## 本轮决定

1. 保持宪法、十二章身份、目标和里程碑不变。前三章依次改进同一份 DSH 导览：第一章得到初稿；第二章以两份项目档案核对导览中的一句话；第三章为其中一项材料补齐来源与使用说明。
2. 章首说清带什么来、学到什么、留下什么；解释首次必要术语，以实际例子区分概念。读者能识别某文件用途即可时，不要求理解其格式或技术原理。
3. 只下载当前章的材料包，在同一观察站中追加目录。通用模板用于后续扩展，前三章不重复填写。路径说明以观察站根文件夹为参照。
4. 提供电脑文件操作说明和未接入时的明确停靠点。已有可用 AI 对话工具可完成第一章起草与手工保存；阅读准备不冒充 AI 实作。不能以文字完善代替 DSH 接入与真实试学。
5. 第二章先看 DSH，再比较 R1，最后回改导览；材料、日期和未知项可以短句填写。第三章默认选同一项 DSH 项目介绍；复用记录面向自己，短说明面向读者，不要求一次为整站选许可或核对全部依赖。
6. 图件保留既有九幅：分别承担情境、概念、证据或历史理解功能。本轮以文字与图片相互解释、静态任务指引为主，不新增装饰图或学习打卡功能。

## 验收与边界

以新手从章首到章末的文档走查验证：每个动作有入口、所需材料、保存位置、完成证据和受阻后的下一步。正文、模板、参考反馈与下载保持一致；工程检查后以 review 0.2.1 上线。详细发现、修改与未验证项见 [联合评审记录](../review/2026-10-29-ch01-03.md)。

这次是 AI 辅助编辑评审，不是独立专家审定或真人试学。安装、账户额度、实际 DSH 任务及学习效果仍需分别验证。
