# ADR-0011：第一章图文与打印书稿共用正本

日期：2026-10-30。状态：实施，内容待维护者评审。

## 决定

依维护者最新指令完成第一章两处插画占位，采用真实 GOSD 报告封面、OD 页面和固定版本 R1 README 作为手绘创作参考。AG-01-02 结构图保持原生矢量；AG-01-03 界面证据不做生成式改绘，以原像素局部放大增强纸面阅读。四图统一登记图号、标题、来源与压缩信息。

Markdown 继续作为正文唯一正本，图件登记表同时服务网页图注与 PDF。新增独立 A4 打印排版脚本，使用嵌入的中文 TrueType 字体、较高质量打印图、页眉页码、完整例题练习与可见参考网址。维护者随后明确要求 PDF 仅在对话中单独交付，不提交 GitHub；网页不保留 PDF 下载入口。

普通 Pages 构建不安装 PDF 排版依赖，也不依赖或复制 PDF。仓库保留正文、排版脚本、字体、图像及摘要；打印交付前单独运行 `python scripts/print_manifest.py`，核对 PDF 与正文、图件、字体和样式输入，过期时先重建并目检。`.gitignore` 排除 PDF，全站检查确保 Pages 产物不含 PDF 或无效下载入口。

## 验证边界

自动检查覆盖单一正本、图件、材料包、网页不含 PDF 的交付约束；打印交付另行检查摘要与过期状态；逐页渲染覆盖版式、字体、图题与编号。二者均不能代替真实试学、维护者内容审定或出版社印前验收。当前交付为可阅读、可打印的图文评审书稿。

详见 [打印规范](../../specs/print-spec.md)、[构建说明](../../textbook/print/README.md)、[图件来源与提示词](../../textbook/assets/figures/sources/ch01-2026-10-30.md)。

## 正式打印清理

按维护者后续评审，章名改为“初识 AI 开源”；打印章首完整写为“第一部分 认识开源”。移除版本日期、宣传语、过程说明与交付栏目，保留正文必要的引用与参考文献。结构图缩小并控制其文字不大于正文；纸面清爽与信息可追溯分别由版式和仓库来源记录承担。

打印专用 JPEG 和字体子集也随书稿作为 `AIOS101-CH01-print-resources.zip` 单独交付，仓库仅保留其来源、授权、摘要与重建说明。网页发布只需要已入库的 WebP / SVG，不依赖该资源包或 PDF。
