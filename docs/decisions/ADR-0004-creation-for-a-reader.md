## 决定

默认示范为已有 DSH 导览的一张配套解释作品：“从材料到导览的角色地图”。目标读者读过项目简介，但还不能区分生成、文件动作与分享。作品帮助其解释一次任务，判断“回答出现但文件未保存”等新情境。它不是重新安装 DSH 的教程，也不是要求所有人画图。

- CH07 学会从使用情境选择小问题，比较现有办法，确定作品形式与可检查标准；保留一份设计说明。
- CH08 把设计转为结构草图，用 DSH 形成实际候选，再由学习者作一次有理由的取舍；保留一个作品及一条关键决定。文字版即可，不要求写代码或生成图片。
- CH09 对候选做内容、使用、理解三类检验，修订一个实际问题并在相同条件下复查。独立自查与真人反馈分开；小样本不推出所有人都能用。

可选指南、音频脚本、数据解说、小工具等形式，均沿用用户—问题—材料—标准主线。替代选题必须调整自己的设计与任务要求，不强迫套用角色地图内容。

原型、示例缺陷和参考反馈均标明作者教学设计，不冒充模型输出、访谈或试学。材料包不预置学习者产物；跨章只携带必要文件。图件用真实物件的出版插画表达创作思路，用可编辑 SVG 表达准确关系，避免反复画表单与核验阶梯。
