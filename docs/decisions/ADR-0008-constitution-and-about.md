# ADR-0008：简化课程宪法，同步关于课程

日期：2026-10-30（北京时间）。状态：按维护者意见实施。

## 决定

维护者要求删除宪法原 5.6“真实研究与产品演示分开”，同步精简相关限制，使宪法更抽象、简洁并为教学创作留出空间；将核心理念同步至 Pages 的“关于课程”。

宪法升为 0.2.1，从十二节收敛为八节，保留使命、五维目标、课程结构、OpenDipper 实践、教学与评价、阅读体验、开放建设。删除原 5.6，并精简产品状态、具体交付清单、工具接入细节、发布门槛及重复提醒。基本的来源、责任和开放原则以简洁表述保留。

宪法规定稳定方向；具体活动、方法、技术和实施安排由相应规格按教学需要设计。本轮不把删除的提醒重新包装为一套新的强制清单。ADR-0007 的课程主线继续有效，实施细节可在本原则下调整；历史记录保留原有时间与语境。

- 本轮不改十二章、实践包、配图、course.json 和其他页面的内容。它们按既定顺序迁移。
