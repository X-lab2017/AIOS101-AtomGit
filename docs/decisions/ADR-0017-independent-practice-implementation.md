# ADR-0017：独立实践设计的分阶段实施

- 依据：[章节标题与实践体系设计评审稿](../review/2026-10-30-titles-and-practice.md)、[ADR-0016](ADR-0016-chapter-titles-and-independent-practice.md)

维护者采纳标题与实践设计，要求依次更新宪法、引言、目录和前三章。每项完成后先对照评审稿检查并优化，与已更新内容对齐后再进入下一项。更新仓库及 Pages，PDF 明确暂不更新，待维护者评审后定稿。

## 实施原则

1. 保留四篇十二章、五维目标、学习矩阵与自主性阶梯。开源与 AI 创作贯穿，章节学习递进与作品是否连续分别设计。
2. 各章核心实践具备独立输入、任务与反馈；允许沿用自己的成果。必要知识前置继续说明，不预设已交齐前章作品。
3. OpenDipper 提供可选数据观察与案例，DSH 及其他合适的 Agent 支持创作。研究报告与交互展示保留为综合示范方向；具体结课范围由教学设计明确。
4. 同步相关规格、配套材料、导航和图中文字。前三章保留有效概念解释、真实案例与图件，减轻过早出现的技术细节和任务依赖。
5. 后九章仅作必要的标题与入口对齐，正文和任务迁移状态明确标注；不借本轮扩大为后九章重写。
6. 案例库预留方向，保留已有教材示范；不虚构新的画像案例、学生作品、运行或社区反馈，不在本轮建设收集平台。
7. 旧 PDF 和打印摘要作为历史交付保留，本轮未进行新版打印排版验收。

分项评审和验证记录见[实施评审](../review/2026-10-30-independent-practice-implementation.md)。
