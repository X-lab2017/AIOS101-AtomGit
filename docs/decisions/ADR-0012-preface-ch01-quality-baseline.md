# ADR-0012：以序言与第一章确立后续章节质量基准

日期：2026-10-30。状态：维护者已确认，纳入编写规范。

## 依据

完成序言与第一章图文、正式打印清理和单独 PDF 交付后，维护者明确提出：“把序言和第一章作为一个标杆和基准了，后续都可以像他们看齐”。

基准为序言 v0.4.0 与第一章《初识 AI 开源》v0.6.0，对应仓库提交 [5c62b9b](https://github.com/X-lab2017/AIOS101-AtomGit/commit/5c62b9b8d046e5828eb9982f7db140769152ffa5)。第一章 PDF 为本轮已单独交付、逐页检查的 16 页 A4 版本。

## 决定

序言提供全书定位、叙述语气、学习动机与真实实践主线的参照；第一章提供讲解深度、概念与案例组织、独立自学、图件和正式打印的参照。共同质量要求写入 [教材体例规范](../../specs/textbook-style-spec.md)，打印细则由 [打印规范](../../specs/print-spec.md) 维护，作者与 AI 协作者按相同标准接续。

后续章节采用正式、准确而易读的标题和语言，提供充分的背景、概念解释、材料、例题和反馈。插图服务于理解，印刷图中文字原则上不大于正文。打印版保持清爽，去除临时版本日期、宣传语、制作和交付栏目；保留必要的学术引用与参考文献，完整制作和核验信息留在仓库记录。

继续保持一份正文正本，网页与 PDF 同步。PDF 仅在对话中单独交付，不提交 GitHub 或 Pages。每章按“逐章立题、研究先行、材料补充、图文共创、上线评审”推进，在评审记录中简述对齐情况与有教学理由的差异。篇幅、节数、图数和实践形式由教学目标决定。

## 验证与接续

本次只更新规范与接续记录，不改正文、图件或打印输入，无须重建已交付 PDF。提交前运行 `python scripts/check_all.py` 检查规格、仓库链接、网站与材料包。

维护者确认的是质量基准，不代表其他章节已通过内容审定，也不代替真人试学或出版社印前验收。后续根据实际反馈改进基准时，同步更新规范与决策记录。
