# ADR-0010：教材正文与数字配套共用内容、各尽其职

日期：2026-10-30。状态：已采纳。依据：维护者要求资源同时用于书籍出版，并补足背景、前置知识、概念定义和自学说明。

CH01 v0.3.0 已有真实故事与完整实践，但叙述偏操作指导。v0.4.0 改为正式教材：连贯解释形成知识结构，案例与练习支持理解；核心材料、完整例题、章末反馈直接进入正文。

正文、在线页和 Markdown 下载共用教材正本；材料包承载界面步骤、接入和保存支持。课堂 90 分钟是教学组织约束，不是全章逐字阅读的时间上限。学习目标和文献在正文出现时，构建不再重复附加。

采用 [教材体例规范](../../specs/textbook-style-spec.md)。本轮仅实施 CH01，保持普通插画占位及现有图号；其他章逐章迁移，不据此宣称全书已达出版标准。后续完成插画、真实试学和出版排版验收。
