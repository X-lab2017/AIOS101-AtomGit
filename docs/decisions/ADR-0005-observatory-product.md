# ADR-0005：把创作篇重新对齐观察站产品

日期：2026-10-29 UTC。状态：本地与内部评审通过；维护者已明确批准本轮发布。本决定替代 ADR-0004 中以角色地图为默认主成果的决定，保留其历史记录。

## 问题

维护者明确指出第七至九章质量不足，要求多参考 Neo Lee PPT 并结合观察站产品设计。旧稿虽然引用产品过程，却把创作主线压成第六章导览的配套角色地图：有用户、原型和核验术语，但没有让项目档案、探究、作品、协作与个人积累形成产品。继续润色这张图不能解决偏题。

## 实际依据

- Neo Lee《建立智能时代的个人工具箱：理解 · 规划 · 创造 · 改进》，英文封面 Skill Set in AI Era，文件名 Skills Set in AI Era.pdf，Autumn 2026，共58页。实际读取提取文本：PDF p24—25创造动机与规划验证、人机合作；p47—48规划/设计/开发/运营；p49用户四问；p50动机、核心问题与比较优势；p51核心/基本/关注能力；p52流程、粗粒度接口及功能衔接；p53输入输出、一致/易用/直观/美感。课件方法由本课程重新演绎，不复制课件图版或公开原文件。
- 已恢复并读取原课程产品蓝图及维护者后续决定：五块为项目档案、理解探究、AI创作、开放协作、个人积累；师生统一使用观察站，后续四篇十二章覆盖旧八章与任意主题方案。当前仓库没有独立PRD，不把旧ADR当用户原方案。
- CONSTITUTION.md、specs/practice-spec.md、practice/template/ 以及前六章已有成果提供范围。文档/网页/手册均可，不把复杂系统开发变成先修。

## 决定

CH07为观察站设计一条用户旅程，CH08使它成为可阅读或可操作的候选，CH09沿任务检验并修订，开始维护和方法积累。默认旅程为辨认项目→查看DSH用途与条件和来源→打开已有导览→决定下一步。角色地图降为可选解释作品，不再统领三章。

五块共同定义产品成长，但本版只打通一个核心路径，不空填五块、不把所有内容都压成三句话。前三章的材料与第四至六章机制学习成为可连接的基础，非重写对象。第十至十二章保留原范围。

配套补齐同一课程内可浏览的作者示范（入口、R1/DSH档案、DSH导览）与空白模板。它是实际内容产品，不是DSH实际运行、真人反馈或学生作品。只发布到既有课程路线，不另建产品或平台。

## 验收

检查任务、材料、作品、图和规格是否同向；示范入口到档案、来源、导览及返回能连通；区分本地静态检查、发布后浏览器检查、DSH实跑和真人试学。工程通过不能代替内容审定。
