# ADR-0021：第三部分以独立任务深化 AI 创作

> 日期：2026-10-31（北京时间） · 状态：依据维护者授权实施；正文待内容评审。

## 背景与决定

维护者要求按第一部分及第二部分入门阅读基线，完成第三部分“开展 AI 创作”三章；依次立题、研究、补充材料、图文编写、自审并上线。中间环节由编写者完成，三章联合提交评审，PDF 暂不更新。

沿用已审定章名与五节目录，不修改宪法、引言及前六章正文。第七章聚焦选题与方案，第八章聚焦构建与表达，第九章聚焦评价与改进；必要术语在使用前解释，纸面保留核心材料、完整例题及反馈。

三项核心任务分别提供 AIInfra 选题材料、开源 Agent 教材的导览方案和来源卡、AI Engineering 配套资源的待改作品。它们是独立输入，不要求前章文件、OpenDipper 访问、指定 Agent 或公开发布；学生可选择延续自己的作品。真实项目事实与课程构造的读者情境、候选和反馈分开。

Neo Lee 用户提供课件重点用于需求理解、范围取舍、原型和人机合作；其他指定资源按问题选材。采用原创归纳与课程图件，不公开原课件，不把配套摘要当作通读原书。现有有效插画复用，含旧观察站关系的 SVG 按新内容重绘；正文内字不大于正文，保留放大入口。

## 验证与后续

更新结构正本、章节规格、实践包、图件登记及页面状态；逐章检查后进入下一章，最后检查任务独立性、术语递进、材料一致性和发布结果。正文状态为 review，不把工程通过等同于维护者审定、真实用户试学或学生 AI 实跑。第十至十二章及早期观察站示范保留现状，明确它们的旧版身份。
