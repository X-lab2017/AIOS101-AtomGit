# ADR-0014：第三章独立升级与第一部分教材联动

- 日期：2026-10-30
- 状态：按维护者确认的策略实施；正文仍为 review

## 问题与决定

维护者要求先完成第三章独立评审材料，再联动前三章，包括各级标题优化，形成教科书级第一部分。第三章旧稿偏重许可检查，且沿用观察站、导览任务，与新简报和项目档案脱节。

采用“初识 AI 开源—打开一个开源项目—开源的力量”三章题名。保留第一章整体认识与给定材料创作，第二章项目全貌及独立材料选择，第三章解释历史、开放机制、复用与共同改进。节标题聚焦知识对象、关系和任务，小节准确说明具体内容；实践小节统一为任务与完成要求、参考成果与分析、自我评价与后续学习，节数按内容决定。

第三章以 Open Source Guides 的 CC BY 4.0 文字改写为完整例题，DSH MIT 为对照，AIInfra PR #364 为真实文档修订。评论与正式 review 列表为空，只记录可见差异与合并，不虚构过程。OD 继续作为贯穿项目，其材料权利状态保留原快照范围。

第一部分沿用同一简报：CH01 开始创作，CH02 依据项目材料修订认识，CH03 落实一项复用条件与一次读者导向改进。成果增量不同，不让学生重复填写同一调查。原版历史和贡献思想重新分配到本章；不迁入其平台操作长表。

## 交付与验证

先完成第三章独立正文、九文件材料包及打印审校，再联动前两章标题与衔接。三个单章 PDF 和含目次、连续页码的第一部分合订稿由同一正本生成，仅在对话交付。来源、图件、脚本与摘要进入仓库，字体和打印大图另随资源包交付。

五维目标在第一部分形成起步表现，不据纸面练习声称完整课程目标已经达到。工程、逐页排版、公开页面检查与维护者评审、真人试学分别记录；既有肖像参考的正式出版事项仍见原来源记录。

本轮不修改第四章及之后的正文或任务。研究依据见 [第三章研究记录](../research/CH03-upgrade-basis.md)，联动评审见 [第一部分评审](../review/2026-10-30-first-part-textbook.md)。
