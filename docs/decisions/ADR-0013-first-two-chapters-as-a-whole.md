# ADR-0013：以整体认识与项目阅读联动打磨前两章

- 日期：2026-10-30
- 状态：采纳；正文仍待维护者内容评审和真人试学
- 依据：课程宪法 v0.2.1、维护者关于第二章偏向模型项目的反馈、AIOS101 原版第一章。

## 问题与决定

第一章的仓库阅读与第二章重复；第二章以 R1 蒸馏关系占据主线，使 AI 开源容易被理解为模型开放。两章共同承担“认识开源”的起步，但应产生不同的学习增量。

第一章回答“AI 与开源怎样联系，为什么值得学，怎样开始创造”：建立模型—产品—系统及软件、模型、数据、内容、社区的整体视野，保留真实报告、四幅图和有引导的一页简报。使用—理解—创造是观察学习活动的三个角度，不替代宪法五维目标。R1 是有边界的入门样本。

第二章回答“怎样读懂一个持续建设的项目”：以 OpenDipper 串联用途、成果、材料、人员与变化，再用 R1、DSH 和课程本身形成简短对照。把仓库、README、文件职责、版本与协作入口放在同一阅读任务中。复用原版 Issue/PR 插图；用精确 SVG 表达项目全貌。蒸馏只保留理解材料差异所需的一段，不教授训练机制。

第三章保留开源历史、许可与复用条件的深入讨论；第十、十一章保留发布与提交协作的具体操作。此次不扩写后续章节，不实际向案例社区发帖。
