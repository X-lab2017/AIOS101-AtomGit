# ADR-0020：第二部分入门支持与图件阅读尺度

- 日期：2026-10-31（北京时间）
- 状态：已按维护者要求实施，内容待评审

## 依据

维护者要求第二部分补足前置术语、基本定义和前后逻辑，在课程宪法范围内贯彻开源学习与 AI 创作方法；图件不宜过大，图中文字建议不大于正文。承接 ADR-0019，范围为 CH04—06 的正文、独立实践支持及共用图件显示规则。PDF 继续暂缓。

## 决定

1. 三章正文与各自材料包升级为 0.5.0，状态保持 review。每章的已审定正式章名、五节分工和任务目标保持；增加章首阅读起点、首次术语解释、具体步骤与章际过渡。
2. CH04 从输入、输出和评价进入样本、参数与误差，补充必要算术与训练概念；CH05 从已有参数的使用进入词元、自回归、概率选择与依据判断；CH06 从请求与返回进入工具分工、文件位置、会话状态与反馈行动。
3. AI 辅助、独立复核、带理由修订与同伴反馈融入各章原有实践。协作可与同伴进行，也可先自查，不另增统一作品或强制公开任务。
4. 图件登记增加可选 `webMaxWidthEm`。正文内居中显示、保持比例，最大宽度随正文字号计算并受栏宽约束；SVG 的最大源字号与显示比例核算为不超过正文。第二部分含文字的插画分别定宽，原始像素和原图放大入口保留。
5. 共用显示规则同时作用于全书已登记图件；没有逐图宽度的插画默认上限为 32 个正文字宽单位。18 幅已登记 SVG 按源字号设置上限，第二部分三幅插画单独检查。该改变属于呈现调整，不重新审定其他章节内容。

## 对齐与边界

宪法、引言、已审定目录及第一部分正文不改写。五维目标相互支持，第二部分重点仍为理解与判断；没有扩充为训练部署或 Agent 开发课程。公开资料、教学设定与实际运行继续区分，原有 A/B 输入及算例不变。

全书图片的正文显示与原图查看是不同尺度；打印排版仍需单独验收。本轮不声称完成真实学生试学、移动设备实测、完整 Agent 实跑或 PDF 更新。具体改动、检查与上线证据见[评审记录](../review/2026-10-31-second-part-reading-ux.md)。
