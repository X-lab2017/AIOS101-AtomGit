# ADR-0001：AtomGit 版课程骨架基线

日期：2026-10-29。状态：按维护者明确要求实施，网站骨架待维护者评审。

采用“用开源来理解 AI，用 AI 来贡献开源”作为核心理念，“理解 AI，学会判断，在开放协作中创造”为育人目标。DeepSeek 与 DSH 是双重身份对象，AI 开源项目观察站是贯穿实践载体，AtomGit 是实践社区，技能集与作品集是学习成果。

采用四篇十二章新提纲，不受旧十二章或此前八章目录限制。新仓库独立创作；旧仓库只按固定提交复用品牌、阅读渲染方法与 SDD 经验。复用身份见 brand/reuse-manifest.json。

采用 Markdown 正文、JSON 结构、静态生成与 GitHub Actions 发布。界面语言只切换导航，不伪造英语教材。暂停的手账、已读标记和想法表单不恢复。保持真实的提纲、草稿与审定状态。

不复制旧教材正文作为新课完成内容；示范项目以资料组织骨架开始，不虚构实操、反馈或贡献。许可未决状态保留，维护者授权课程复用不自动等于向公众授予统一许可。
