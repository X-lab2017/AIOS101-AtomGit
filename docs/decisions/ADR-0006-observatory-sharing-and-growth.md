# ADR-0006：让观察站从个人作品走向协作与成长

日期：2026-10-30（北京时间）。状态：本轮实施决定，正文待维护者评审。

## 依据与范围

维护者授权撰写第十至十二章，要求每章完成后评审优化再进入下一章，三章联合复审后更新仓库与现有 Pages。延续 ADR-0005 的观察站产品主线，不回退到单篇导览润色。前九章正文、课程宪法及四篇十二章身份保持不变。

本轮读取用户提供的《AtomGit.pptx》全部三页文本。第 1 页的平台定位提示平台与创作工具的不同职责；第 2 页的提交、反馈与评审提示版本记录怎样支持协作；第 3 页提示不同开放对象需要不同托管与使用条件。转化为学习机制，不照搬平台规模、排名、排他性宣传与商业事件。没有公开原课件，没有把文本提取称作逐页视觉审阅。

操作依据为 2026-10-30 实际阅读的 AtomGit 官方帮助，包括项目创建、浏览器文件编辑、提交、Issue、PR、Fork 和评审。网页操作说明独立放入材料包，正文解释稳定概念。课件不能替代现行操作文档；文档中部分截图仍使用 GitCode 名称，明确界面可能变化，不能声称本轮已经登录实操。

## 决定

- CH10：把 CH09 已核验的观察站整理成读者能使用、能定位版本的作品。核心采用浏览器编辑文本文件，不要求 Git 命令、网站部署或自动连接 DSH。
- CH11：围绕一个有用的改进学习 Issue、差异、分支与 PR 的关系。文档贡献是完整贡献路径；不强迫给上游提交教学噪声，不用自评冒充他人评审。
- CH12：从真实作品中提炼人的方法与判断，将方法用于新的 AI 项目问题。技能集不等同于 Skill 文件；平台热度不代替能力证据。以 Transformers 的对象与使用条件作作者迁移示例，学生选择自己的迁移任务。
- 示范保留作者身份；材料包包含空白任务支架与明确标注的教学演练，不预填学习者成果。实际分享、他人使用、协作接纳、模型运行分别记录。
- 延用 Open Folio 视觉；叙事插画用实物隐喻，版本及协作关系用可编辑 SVG。新增图号 AG-10/11/12，图注统一由 manifest 生成。

## 验收

逐章检查背景与概念、动作和结果、前后衔接、来源与插图、无接入路径及自学反馈，再开始下一章。联合检查示范/模板/材料包、主页/目录/关于、下载与链接。发布前检查远端变更，发布后核对 Actions 与线上版本；浏览器、账号实操、真实 DSH 和真人试学各自陈述证据范围。
