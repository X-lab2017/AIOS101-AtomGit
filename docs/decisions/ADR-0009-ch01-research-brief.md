# ADR-0009：以一页研究简报开始 OpenDipper 主线

日期：2026-10-30；状态：依维护者本轮指令实施，正文待评审。

## 决定

CH01 从 DSH 文件导览改为 R1 一页研究简报。依据用户已认可的深度研究方案，以及报告制作、行业工作坊、全专业学生、90 分钟与 DeepSeek 网页端的补充。依照“逐章立题、研究先行、材料补充、图文共创、上线评审”推进。

全书概览采用宪法 v0.2.1 四篇十二章，说明报告＋动态展示＋AtomGit 项目的最终方向；course.json v0.2.0 仅表示 CH01 开始迁移，CH02—12 未因此自动完成新版任务。P4 统一为“开放协作”。

首课只需浏览器、DeepSeek 网页服务和熟悉的文档工具。OD 提供观察线索；R1 是研究对象；DSH 后续教授；AtomGit 是作品长期协作空间。参考例子由编写者提供，不写成真实模型输出、实训结果或学生反馈。

维护者要求普通插画占位，因此本轮仅保留两处带图号与图题的文字占位；新增实际 SVG 全书结构图及 OD 界面截图。review 可呈现这些已明确约定的占位，published 前仍须完成图件验收。

## 兼容与影响

第一章正文、八文件材料包、提示词、目标和来源同步。材料包根目录改为 ch01，不再强制第一课创建观察站目录。CH02—03 仅补衔接，明确 DSH 作为第二对象及参考材料选项；其他章节继续后续研究升级。旧配图保留源文件与历史元数据，但不再作为 CH01 当前图件发布。

不改母版 Logo、不增加已读标记或手账等功能，不把课程宪法变成操作清单。后续需通过真实试教校准 90 分钟安排。
