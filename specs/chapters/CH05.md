## 本轮正文设计 · 0.2.0

日期：2026-10-29。保留上游学习目标与任务，承接第四章的训练/预测区分。

- 入口：观察站导览中一条听起来合理的回答，能否找到足够依据？
- 概念顺序：逐步生成/词元 → 当前上下文 → 训练形成的能力与外部材料 → 错误和证据不足 → 一个问题、只改变材料的对照 → 有边界的修订。
- 贯穿问题：按照固定版本指南，新用户能否打开 Web UI 就直接输入任务？分别给项目简介 A、同一简介加使用条件 A+B。固定问题、指令与评价标准。
- 材料：复用已核验 DSH 固定文档，重新阅读相关原段；课程转述含位置与版本。当前产品行为不据历史文档推断。
- 核心不依赖账号：先独立依据 A 与 A+B 作答，再评审两份明确标注为编写者构造的回答，保留初判与修订。该路径评价证据判断，不声称测量模型效果。
- 可选真实调用：同模型/模式、各开新会话、固定提示词，记录可控与不可控条件；保留所有输出。无运行、模型身份不明或工具无法停用均如实写明，不预设 B 一定更好。
- 图件：AG-05-01 图书馆核对引文的手绘实物概念场景；AG-05-02 训练与当前上下文双时段 SVG；AG-05-03 对照条件 SVG。无虚构 UI、实测数据或模型排名。
- M05：ch05 内留下条件、两份结果、逐条证据与局限，回到同一份导览修改一句话。反馈区分错误、缺依据和未完成验证。
- 边界：不把流畅表达当事实证据；不把一次对照称因果证明或模型排名；不把提供材料说成训练权重；不给出幻觉已被消除的承诺。
