# 视觉与图件规范

沿用 AIOS101 Open Folio / 开卷 v1.0.0：纸白 #F6F3EB、深墨 #1D2433、靛蓝 #5146D9、珊瑚橙 #F27A59、青绿 #3F958D。暗色主题使用相应母版，不对 Logo 使用滤镜反色。

课程标志与 X-lab 出品方署名各自保留净空，AtomGit 版作为文本标签，不拼改品牌标志。资产路径与上游固定提交见 brand/reuse-manifest.json；新增网页布局属于本版适配，未改变原视觉母版。

教材插图采用多样化的科技出版插画，优先真实人物、实物、项目界面与清楚的视觉隐喻。精确关系、数据和文字使用可校验的图形；真实界面数字和状态保留原始证据。

新增图件登记 textbook/assets/figures/manifest.json：id、file、title、alt、width、height、source、license、date。图号采用 AG-章号-序号，图题置底；旧仓库图号只作来源身份，不直接重用为本版图号。适度压缩；保留适合放大的文件，检查 390px 阅读和实际放大文字。

## 正文中的图件尺度

图件服务连续阅读，不默认铺满正文栏。登记表可用 `webMaxWidthEm` 指定相对正文字号的最大宽度；渲染时居中、保持比例，并受可用栏宽限制。调整正文字号时，图件允许随之适度变化。

正文内显示的图中文字原则上不大于正文。精确 SVG 根据源坐标中的字号与显示比例核算，含大字的插画按实际画面单独定宽；不把截图中的界面或插画原图重新绘字。图题与来源仍为可选择的网页文字。手机上保留原图放大入口，核心关系同时在正文解释；不以整图缩小代替必要的讲解。打印版仍按其排版规范单独验收，本轮不重建 PDF。
