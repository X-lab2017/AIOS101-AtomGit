# 学习评价规格

> ID：ASSESS-ATOMGIT · 目标版本：0.2.0 · 状态：评价方向已对齐宪法，具体任务与量规待迁移及试教校准

| 成果 | 最低可观察表现 | 证据 |
| --- | --- | --- |
| LO1 理解 | 解释 AI 与开放协作机制，说明研究对象、数据和关系的含义 | 小实验、机制解释及条件变化分析 |
| LO2 判断 | 对关键主张选择依据和方法，说明比较条件及结论范围 | 来源、研究分析与选择理由 |
| LO3 创造 | 完成服务具体读者的研究报告与动态页面，核对内容一致性和交互用途 | 报告、页面、项目源码及使用说明 |
| LO4 协作 | 在 AtomGit 开源研究项目中提供或回应具体反馈，推进有价值的改进 | 问题、差异、回应与个人贡献 |
| LO5 迁移 | 从研究与创作中提炼方法，在新的项目、数据或读者条件下调整并检查 | 方法条目、新尝试及结果解释 |

各维度暂采用“待补 / 基本达成 / 熟练 / 灵活运用”四级描述，后续通过真实样例校准具体判据，暂不固定权重。AI 参与本身不扣分，作品精美不能替代依据。报告核验问题、方法与关键主张，页面核验交互、数据口径、来源与报告一致性，开源项目核验使用、许可、版本和协作。

本轮仅对齐评价方向，尚未完成新版活动、完整量规或试学。既有练习证据可以复用，但不能据此直接认定新增的报告、动态页面或开源交付已经达成。

小组成果仍需个人解释自己的判断和贡献。自学反馈可来自预设材料，但应准确标注；对真实社区参与的评价需使用真实记录。
