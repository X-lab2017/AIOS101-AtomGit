# 学习评价规格

> ID：ASSESS-ATOMGIT · 状态：待试教校准

| 成果 | 最低可观察表现 | 证据 |
| --- | --- | --- |
| LO1 理解 | 解释训练、生成与工具执行的区别 | 小实验和个人解释 |
| LO2 判断 | 检查三个关键点，指出条件和局限 | 来源、核验与比较记录 |
| LO3 创造 | 完成服务具体读者的可用作品 | 作品及使用说明 |
| LO4 协作 | 提供或回应具体反馈，形成实质改进 | 问题、差异与回应 |
| LO5 迁移 | 说明个人能力，将方法用于新问题 | 技能条目与迁移记录 |

各项采用“待补 / 基本达成 / 熟练 / 能够迁移”四级。第一轮暂不固定权重，先用试学样例校准。AI 参与本身不扣分，作品精美不能替代依据。文档核验关键陈述，工具核验输入输出和使用行为，按作品形态选择检查点。

小组成果仍需个人解释自己的判断和贡献。自学反馈可来自预设材料，但应准确标注；对真实社区参与的评价需使用真实记录。
