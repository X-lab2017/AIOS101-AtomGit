# 内容与证据规范

正文体例遵循 [教材体例规范](textbook-style-spec.md)，书籍和网页共用内容正本。

正式正文必须先交代读者需要的背景，首次出现的技术术语用普通语言解释，再给英文或缩写。每章有真实情境、机制解释、一个小任务、可检查证据及自学反馈。避免名词堆砌和跨越式步骤。

- 来源实际阅读后登记，保留题名、URL、访问日期、适用版本和引用位置。
- 区分事实、官方自述、个人观察、推断、模拟与未知。
- 实际运行记录工具版本、模型配置、材料、条件、日期和结果；网页截图并非本课程实测。
- DeepSeek 公开材料的版本与 DSH 实训使用模型分别记录。
- 不编造实验、用户反馈和社区贡献，不使用 AI 生成图替代真实数字或界面证据。
- 免费入口、开源许可和 API 费用分别说明；敏感目录和密钥不进入公开材料。

正文状态只在文件顶部维护。维护者明确要求的图件占位可在 review 阶段呈现，须有唯一图号、图题和绘制说明；published 前替换并验收。章节框架允许 outline，正式发布正文不能保留未处理占位符。来源索引见 [sources.json](sources.json)。
