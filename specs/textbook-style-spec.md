# 教材体例与数字配套规范

正文同时服务书籍阅读与在线自学。以连贯的概念解释和知识组织为主体，案例、图件与实践帮助理解；网页承载阅读导航和操作支持。维护者已确认序言 v0.4.0 与 CH01 v0.6.0 为后续章节的质量基准，其他章节随内容升级逐章对齐。

## 序言与第一章质量基准

[引言（原序言）](../textbook/preface.md)提供全书定位、叙述语气和学习动机的参照；[第一章《初识 AI 开源》](../textbook/chapters/CH01.md)提供概念讲解、材料分析、图文组织、独立自学和打印交付的参照。确认版本与执行方式见 [ADR-0012](../docs/decisions/ADR-0012-preface-ch01-quality-baseline.md)。

| 维度 | 后续章节对齐要求 |
| --- | --- |
| 叙述与主线 | 用平实、正式而有亲和力的语言，从真实问题进入知识；说明本章怎样支持理解 AI、开放协作及研究作品的成长。 |
| 讲解深度 | 交代背景和必要前置知识，解释首次出现的重要术语，用例子说明关系和方法，避免只列结论或步骤。 |
| 案例与证据 | 以真实项目和公开材料支持分析，区分事实、判断与教学示例；保留必要引用和来源，不虚构运行、贡献或反馈。 |
| 自学完整性 | 纸面包含核心材料、例题分析、小结、练习与参考反馈，读者能够独立理解和思考；工具操作另配条件与步骤。 |
| 图文表达 | 图件帮助解释内容，图题、来源和正文相互对应；沿用科技出版视觉风格，截图保持真实，排版后的图中文字原则上不大于正文。 |
| 正式打印 | 标题准确、层级完整，章首写明部分名称与章号；移除临时版本日期、宣传语、制作说明和交付栏目，参考文献保留主要内容与必要出处。 |
| 同步交付 | Markdown 与图件登记表为共用正本；网页和 PDF 一致，PDF 逐页检查后仅在对话中交付，不提交 GitHub 或 Pages。 |

以教学需要决定篇幅、节数、图数与实践形式，不要求复制第一章的七节、四图或 16 页。后续每章在评审记录中简要说明与基准的对齐情况，以及有教学理由的差异。基准允许随维护者反馈和试学结果改进，调整时同步规格与决策记录。

当前引言 0.5.0 将五维目标、学习矩阵与自主学习阶梯纳入读者导向，保留既有叙述与图文质量。全书新目录按 ADR-0015 单列评审，审定后再按章落实；历史质量基准不等于新目录已经审定。

## 让读者具备继续学习的条件

先说明问题的背景与学习价值，再交代理解它所必需的概念。首次出现的重要术语，应提供普通语言解释、必要的正式名称和具体例子；说明易混概念的关系。能由后续章节解释的机制，可先建立直观认识并指明后续位置，不以缩写或产品名称替代解释。

定义、事实、材料分析和作者判断应能辨认。模型、服务、工具与平台按各自角色说明；通用概念与某个产品的实现不可混用。来源遵循 [内容与证据规范](content-evidence-spec.md)。

## 形成完整的学习单元

### 标题层级与章际分工

章名先给出明确的学习对象或中心问题，可用副标题限定范围；同一部分的章名应体现递进，避免堆叠口号。节标题标明一个概念、关系或方法，小节标题承接该节的具体内容；减少连续问句、临时任务语和意义相近的重复标题。标题不要求字数一致，也不以整齐为由合并不同知识层次。

第一部分依次为“初识 AI 开源—打开一个开源项目—开源的力量”：第一章建立认识，第二章训练项目阅读，第三章解释开放、复用与共同创造。综合实践统一“任务与完成要求—参考成果与分析—自我评价与后续学习”，三章持续完善同一份研究简报。标题调整须同步正文、课程结构、章节规格、配套入口及打印目录。

### 单元内容与自学反馈

按内容需要组织导入、学习目标与阅读准备、分节讲解、例题或案例分析、综合实践、本章小结、思考练习与参考反馈。结构可以调整，不要求每节套同一模板。例题要解释理由与方法，练习应检查理解、判断及迁移，反馈应说明如何改进，避免只给结论。

核心分析材料应在正文可读。纸面读者不打开链接，也应能理解概念、分析例题并进行思考；真实工具操作需要网络时，在配套资源提供条件与步骤。开放题允许合理的不同答案，评价依据应清楚。

## 区分稳定正文与操作支持

正文保留研究目的、方法、材料、示例、图号图题与来源。账号准备、按钮位置、下载保存、教师课时分配放在配套实践或教学文件中，并标注适用日期。不要让教材主体成为网页操作清单，也不要把全部学习材料移出书本。

教材阅读量与课堂课时分开安排：课程可以选取重点讲授、实践、预习和复习，不假定学生必须在一节课读完整章。正文语气平实准确，避免聊天式承诺、宣传式评价、重复的风险提醒和无法解释的新术语。

## 一份正本，多种呈现

textbook/ 下的 Markdown 是内容正本。章节学习目标、标题与 course.json 对齐；正文已经写出目标和参考文献时，网页不重复插入同类内容。例号在章内顺序编号，图号沿用视觉规范；教材示例与材料包保持语义、事实和任务要求一致。

插画在维护者要求时允许于 review 阶段以唯一图号、图题占位，正式出版前完成替换与图文验收。图像放大、手机阅读、下载材料与打印排版分别检查；网页上线不代表出版排版已经完成。
