# 章节打印书稿规范

正文正本仍为 textbook/chapters/ 下的 Markdown。打印稿由同一渲染器读取正文、图件登记表与专用印刷样式生成，不另维护一份删改过的教材。

- 当前范围：CH01 v0.7.1（四幅图）、CH02 v0.4.1（两幅图）与 CH03 v0.3.0（四幅图），完整材料、例题、练习及反馈；A4 单页式排版，可按实际大小双面打印。
- 沿用 Open Folio 色彩，页面以白底和深色文字为主；宋体正文、黑体标题，中文字体子集嵌入 PDF。图题与来源随图，不跨页分离。
- 插画使用较高质量的打印 JPEG；结构图保持矢量；截图保留原像素，关键文字通过局部放大改善可读性。正文说明应在黑白打印时仍能独立成立。
- 页眉清楚标示书名与章名，页脚只放页码；参考文献保留作者、题名、来源及简洁的可见网址。版本和交付信息留在仓库记录，纸面不显示“放大查看”等仅在线有效的交互文案。
- textbook/print/manifest.json 记录页数、尺寸、PDF 摘要及全部内容/图件/排版输入摘要。打印交付前单独检查一致性，正文变化而 PDF 未重建时阻止交付。PDF 不提交 GitHub、不复制到 Pages，网页构建不依赖本地书稿。
- 每次重建检查所有页面的字体、分页、表格、图题、来源、孤行和文字范围。自动校验不替代视觉检查、内容审定与真实试学。

流程与依赖见 [打印构建说明](../textbook/print/README.md)。本稿为可打印评审书稿；若进入出版社生产，按其开本、色彩配置和印前规范另行输出。

## 正式打印版式（以 CH01 0.6.0 为基准）

章首完整标示部分名称与章号；正文不放版本日期、过程性说明、宣传语或交付栏目，页眉仅保留书名和章名，页脚只放页码。参考文献保留作者、题名与来源；核验日期、固定版本说明等制作信息留在来源记录。结构图打印宽度 110 mm，最大字号约 10.1 pt，小于正文 10.8 pt；网页最大宽度 520 px。

上述结构图尺寸为第一章 AG-01-02 的实例。其他图件按内容与页面调整，排版后的图中文字原则上不大于正文，并保证印刷可读性；信息过密时优先重排、拆图或局部放大。清理制作说明不删除正文理解与证据判断所必需的引用、观察日期及版本背景。


第一部分合订稿由相同章稿重新排版，包含可点击目次、各章页眉与连续页码；摘要另存 textbook/print/part-manifest.json。三章采用同一字体与样式，单章和合订分别逐页检查。
