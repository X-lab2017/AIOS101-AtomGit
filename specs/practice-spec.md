# 贯穿式实践规格

> ID：PRACTICE-OBSERVATORY · 上游：CONSTITUTION.md、course.json

AI 开源项目观察站是贯穿载体，不另立为课程名。M01—M12 对应十二章，每个里程碑的任务与证据由 course.json 生成。实践说明在 practice/README.md，示范在 practice/demo/，可复制模板在 practice/template/。

教师与学生采用同一种组织方式；示范材料的阅读、运行与反馈状态独立记录，不替学生预填成果。课程社区、同伴项目与上游贡献按实际位置标注。

MVP 最低范围：共同观察 DeepSeek 与 DSH，选择一个问题，形成一个可用作品，完成三个关键点核验和一轮修订，整理技能与作品证据。形式可以是图解、指南、报告、网页、工具、模板、Skill 或插件。

验收：模板可下载且无账号密钥；材料来源与使用条件明确；任务适配无编程基础；实践入口可返回相应章节；不能仅凭保存文件判定已经学会。

## 创作篇的产品增量（0.3.0）

五块内容为项目档案、理解探究、AI创作、开放协作、个人积累。M07—M09以一条可用旅程连接既有成果，不把单篇解释图当成观察站整体，也不一次空填全部功能。核心可用文档实现，网页和手册等形式同样可行。作者示范在practice/demo，学习者空白支架在practice/template；作者内容产品与运行/反馈证据分开。

## 分享、协作与积累（CH10—12）

M10 沿用 M09 的候选，浏览器整理 README 与作品，保留当前入口和固定版本，检查访问。M11 用具体问题、差异和回应连接真实协作；个人分支/PR 演练与实际帮助他人分别记录。M12 选择代表作品和人的方法，提出未由示范解答的新问题，并以新情境结果修订技能条目。允许复用原来的作品说明与记录，不要求每章另填表。平台统一教学空间与真实试学仍需落实。
