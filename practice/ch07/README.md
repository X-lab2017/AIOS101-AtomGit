# 第七章材料包：设计一件开源主题作品

> 状态：review
> 版本：0.4.0

本包提供 AIInfra 阅读卡与读者情境，可以独立开始，无需前章作品、OD 访问或编程。目标是形成有理由、可检查的创作方案，不必在本章制作成品。

## 开始前

需求说明读者要完成什么，方案说明准备用什么办法；设计假设尚需验证。先读[材料与情境](materials/reading-cards.md)，必要概念见[第七章](../../textbook/chapters/CH07.md)。

## 完成一份方案

先写自己的问题理解，将材料与[提示](plan-prompt.txt)交给可用 AI，请它提供两个不同方案。比较材料是否足够、用途能否检查，选择一个并解释一项取舍。用[方案支架](work/design.md)整理范围、结构、来源、人机分工、三项完成标准和一个待验证假设。

聊天工具可直接粘贴材料；具备文件读取能力的 DSH 或其他 Agent 可在 ch07 工作区阅读同样材料。请自行保存方案；提示不要求联网、安装或发布。工具是否实际读取文件、是否产生文件，以可见结果为准。没有 AI 时先比较正文给定方案，标明方案分析，工具可用后补充实际合作。

## 参考与反馈

先完成自己的判断，再看[参考方案](examples/design-reference.md)与[自查反馈](examples/self-check.md)。参考是编写者示范，不预填学习者运行或访谈。可请同伴指出一处含糊安排，依据真实反馈修订；没有同伴时完成自查。

核心交付是一份方案，比较和说明可写在其中。第八章另有独立方案，不要求把本章文件复制过去；愿意延续者可以自行选择。材料来源与使用范围见[来源说明](sources.md)。
