# 第七章材料包：选择一个值得做的小问题

> 状态：review
> 版本：0.2.0

## 带上已有的观察

解压后把 `ch07` 放入观察站。回看自己的导览、项目档案或第六章笔记；这一章不需要重新安装软件，也不要求使用 AI。

## 只完成一份设计说明

打开 [work/design.md](work/design.md)，用几段短文写明读者、问题、现有办法、材料、范围与三个检查标准。选择教材角色地图示范也可以，但要标明尚待验证的假设。

不必收集访谈数量。自己走过的阅读路径可以提供线索；同伴的话只在实际得到时记录，未经允许不附个人信息。

## 准备进入第八章

设计说明能回答“给谁做、为什么做、做到哪里、怎样检查”，就可以开始做草图。把它的副本带入第八章 `materials/design.md`。材料包不包含伪装为你已完成的设计。
