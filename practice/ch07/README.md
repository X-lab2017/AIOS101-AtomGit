# 第七章材料包：设计观察站的一条使用旅程

> 状态：review
> 版本：0.3.0

先打开[最小观察站示范](../demo/README.md)，沿入口找项目、依据和作品，再回看自己前六章的成果。用[设计支架](work/design.md)写清用户四问、概念白板、能力分层与第一版旅程。短文和草图都可以，不要求把五块内容一次填满。

把已有档案、导览和探究的实际位置写进设计，指出一处缺口如何处理。示范的用户情境仍是待验证设计假设，不冒充你的访谈。

下一章将设计副本放入 `ch08/materials/design.md`，把要用的事实与作品整理为输入。产品形式可以是文档、网页、手册等；先保证一条路径可用。
