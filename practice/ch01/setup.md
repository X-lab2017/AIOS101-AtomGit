# 第一章开始前：工具与文件准备

核对日期：2026-10-29。材料版本：0.2.1。以下依据官方说明整理，尚未完成本课程的安装、账号、模型调用与文件操作实测。软件界面会变化，以所用版本和官方文档为准。

## 先学会打开与保存一个文字文件

纯文本只保存文字和换行，不带文字处理文档的复杂排版；本课的 Markdown 文件可以按纯文本处理。先完成这一步，再接入 AI。所需文件都在解压后的 `my-ai-observatory` 中；不要直接在 ZIP 预览里编辑。

1. 在文件管理器中进入 `materials`，选择 `source-a.md`，用纯文本编辑器打开。Windows 可用记事本；Mac 可用“文本编辑”。看到 `#`、短横线和网址是正常的，暂时不需要排版预览。
2. 回到上一层，再进入 `work`，打开 `record.md`，在“日期”后填写实际日期并保存。关闭后重新打开，确认修改留了下来；原始材料 A、B 保持不变。
3. 需要手工保存 AI 初稿时，新建纯文本文档，粘贴完整正文，选择“另存为”或相应的保存操作，位置选观察站里的 `work`，文件名填 `guide-v1.md`。它若已存在，就换一个未使用的新名字。
4. 保存为纯文本；如可选择编码，使用 UTF-8。Mac“文本编辑”默认可能是富文本，应先转为纯文本。检查完整文件名，避免自动追加 `.txt`。再从文件管理器打开，核对中文与内容。

只把富文本文档的后缀改为 `.md`，不会改变内部格式。如果纯文本文件被加成 `.md.txt`，显示完整扩展名后再改名；如果一时处理不了，可先保留能正常打开的 `.txt` 初稿，记录实际路径，稍后再统一文件名。学习的重点是找到并核对作品，不是被一个后缀挡住。Mac 的具体入口可参照 [Apple 文本编辑指南](https://support.apple.com/guide/textedit/welcome/mac)及[保存设置](https://support.apple.com/guide/textedit/change-textedit-settings-txted1063/1.20/mac/27)。

## 推荐路径：已有可用 DSH

1. 确认工具来源。由 [DeepSeek Harness 官方产品页](https://www.deepseek.com/en/harness/)进入官方提供的下载或说明。本次查阅页面列有 Windows 64 位和 Apple Silicon Mac 下载；其他环境按官方文档核对。本课不要求学生从源代码安装。
2. 记录实际安装的工具版本。可先查找“关于 / About”入口；找不到时记录你能够确认的安装来源和日期，不把文档的提交编号当成软件版本。
3. 按当前界面完成账号或模型接入，确认可以发起普通会话。本课材料 B 使用的是 Web UI 指南，不能把它直接当作所有桌面版本的逐屏截图教程。使用 Web UI 还需要已有可用服务；材料包不会启动服务。
4. 解压材料包。把其中的 `my-ai-observatory` 文件夹选为当前工作区。工作区是本次任务读取与保存文件的位置。
5. 新建会话，记录实际选中的模型，再进入第一章任务。如果无法发送消息，先检查是否选中工作区、是否配置了可用模型，以及服务是否可用。

Web UI 指南中的准备顺序是配置模型、选择工作区、创建会话。账号、接口和可用额度是不同条件；开源工具不等于所有模型服务永久免费。教学方应提供经验证的可用方案，本章不要求学习者临时付费。

API 是程序之间约定的调用接口，API 密钥是调用服务的凭据。只在正式配置入口使用，不写进项目、提示词、截图或练习记录。不要把别人的凭据拿来练习。未落实接入时，记录“尚未接通”，不要将文档里的演示当成自己的运行。

## 可替代路径：已有可用 AI 对话工具

把材料 A、B 的全文粘贴给工具；使用第一章的提示词，但将文件保存要求改为：“请输出完整 Markdown 正文，我会手工保存；不要声称已经写入我的电脑。”

将结果复制到文本编辑器，用 UTF-8 编码保存为 `work/guide-v1.md`。若编辑器自动补 `.txt`，检查最后的完整文件名。记录所用工具和模型；没有显示模型名称就写“工具未显示”，不猜。执行方式写“AI 起草，由我手工保存”。

这条路径能够练习表达需求、给出依据、核验内容和保存作品；它没有验证 DSH 的文件工具。之后有可用环境时，可用新文件名补做 DSH 任务并比较。

## 暂无可用 AI 环境

先阅读材料，自己判断第一章中的三个例句，再与检查参考比对。这是有价值的准备，但不能记为已完成 AI 创作。恢复接入后再补做实际生成和文件检查。现在可以进入第二、三章的阅读任务，以参考材料为练习对象，并注明自己还没有导览产物。

## 遇到阻碍时

| 现象 | 先检查什么 |
| --- | --- |
| 输入框不可用 | Web UI 是否选择了工作区，模型与服务是否就绪 |
| 找不到材料 | 工作区是否选中了展开后的文件夹；其内是否有 materials |
| 工具说完成，却找不到文件 | 核对实际路径；请其明确是否保存，或自己保存并记录 |
| 操作要求突然扩大 | 是否仍属于两份材料与一个新文件；不理解就暂停并问原因 |

本章只需要读取两份材料并创建一个新文件，不需要安装插件、连接代码平台或运行命令。实际工具也可能失败；如实保存进度和问题，比编造“已成功”更有用。
