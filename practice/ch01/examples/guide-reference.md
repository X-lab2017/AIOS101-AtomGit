# 参考例子：给第一次接触 DSH 的同学

说明：以下是编写者借助 AI 起草后按材料核对的教学参考，不是 DSH 实际运行产物，不是学生作品。没有唯一标准答案；先完成自己的检查，再对照结构。

## 它是什么

DeepSeek Harness，简称 DSH，是 DeepSeek 开发的开源智能体框架。可以先把它理解为把模型与工具组织起来的软件：模型生成内容，工具帮助处理具体任务。[A1][B3]

## 可以怎样用

官方指南介绍了读取、编辑工作区文件等能力。工作区就是当前任务的文件位置。你可以把两份材料放进去，请它整理一份导览，再亲自打开结果核对。文档介绍的能力不表示这次任务已经成功。[B3]

## 开始前确认什么

Web UI 指南从服务已经启动的状态开始，还需要配置模型、选择工作区。操作是否询问你，要看权限策略。先确认实际环境与可用条件；项目采用 MIT 许可证，不能据此推断所有服务都免费。[B1][B2][B4][A4]
