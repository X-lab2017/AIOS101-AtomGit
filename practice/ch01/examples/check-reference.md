# 修订与自查参考

以下由课程编写者构造，帮助理解评价标准，不是实际模型出错记录。

## 一次有理由的修改

修改前：“星图证明 R1-GGUF 比 R1 更好。”

修改后：“OD 记录了二者的模型派生关联；性能差异需要另查测试条件与结果。”

理由：材料 B2 支持“存在关联”，B3 说明其来源与方向限制；材料并没有提供性能比较。修改让结论与已有依据相称，也保留了后续研究空间。

若自己的初稿没有类似问题，可以改进术语解释、内容顺序、读者需要或下一步问题，不必为了交作业制造错误。

## 综合实践的评价依据

| 观察点 | 可以对照的表现 |
| --- | --- |
| 对象清楚 | 写出具体模型项目；没有把聊天网页与 R1 等同 |
| 发现有依据 | 读者能顺着材料编号与来源找到依据；关系未被写成效果证明 |
| 读者能理解 | 新词有必要解释；至少说明一个与读者有关的后续问题 |
| 自己作了判断 | 指出一次修改及其理由；不只复制 AI 的评价 |

## 不打开 AI，再解释三件事

1. 研究对象是具体模型项目；起草工具是聊天服务。后台模型身份要看明确说明，不能根据研究对象猜测。
2. 说明自己的句子怎样改变、为什么这样改变。没有唯一标准句，理由应能回到材料或读者需要。
3. 更换读者后，调整已有知识假设、解释和任务；事实依据不随读者改变，需要补的信息应继续调查。

如果还解释不清，回到相应材料改写自己的简报，再试一次。参考简报可供比较，不替代个人创作或课堂试学。

## 教材章末练习反馈

以下与 CH01 v0.4.0 的六道章末练习对应，题目与反馈也完整保留在正文。

**第 1 题。**不能。自动保存可以由明确规则触发，是否采用机器学习，要看系统是否利用数据形成或调整相关模型。生成摘要是生成式 AI 的典型任务，但判断某个具体产品的实现仍需要产品材料。关键是区分功能表现与实现方法。

**第 2 题。**依据不足。研究 R1 与使用网页服务是两件事。需要服务对实际模型的明确标识或其他可核对的运行信息；无法确认时，应记录实际服务名称，不推定后台模型。

**第 3 题。**三者分别涉及费用、访问与授权条件。免费不必然意味着代码开放，能够阅读也不必然允许修改传播。应根据所用材料查阅适用说明，而不是从一个标签推导全部条件。

**第 4 题。**第一、第三项受到材料 B 支持；第二项缺少任务、条件与测试结果；第四项把“当前材料未显示”扩大成“现实中不存在”。资料范围、记录方式或时间差异都可能影响能否观察到关系。

**第 5 题。**答案可以不同，但应确定具体对象（如 R1）、读者已有知识、使用材料及一页简报的结构。例如，限定材料 A、B，使生成与核对围绕相同依据展开；限定读者，有助于决定术语解释的深浅。

**第 6 题。**可以从教学、管理、设计等专业问题出发。例如，研究模型对某课程概念的解释是否准确，需要具体概念、参考答案、评价方法与实际输出。材料 A、B 只提供项目身份与关联，不能直接证明教学效果。评价重点在于问题与所需证据是否相称。
