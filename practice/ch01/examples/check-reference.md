# 修订与自查参考

以下由课程编写者构造，帮助理解评价标准，不是实际模型出错记录。

## 一次有理由的修改

修改前：“星图证明 R1-GGUF 比 R1 更好。”

修改后：“OD 记录了二者的模型派生关联；性能差异需要另查测试条件与结果。”

理由：材料 B2 支持“存在关联”，B3 说明其来源与方向限制；材料并没有提供性能比较。修改让结论与已有依据相称，也保留了后续研究空间。

若自己的初稿没有类似问题，可以改进术语解释、内容顺序、读者需要或下一步问题，不必为了交作业制造错误。

## 看什么，而不是数什么

| 观察点 | 可以对照的表现 |
| --- | --- |
| 对象清楚 | 写出具体模型项目；没有把聊天网页与 R1 等同 |
| 发现有依据 | 读者能顺着材料编号与来源找到依据；关系未被写成效果证明 |
| 读者能理解 | 新词有必要解释；至少说明一个与读者有关的后续问题 |
| 自己作了判断 | 指出一次修改及其理由；不只复制 AI 的评价 |

## 不打开 AI，再解释三件事

1. 研究对象是具体模型项目；起草工具是聊天服务。后台模型身份要看明确说明，不能根据研究对象猜测。
2. 说明自己的句子怎样改变、为什么这样改变。没有唯一标准句，理由应能回到材料或读者需要。
3. 更换读者后，调整已有知识假设、解释和任务；事实依据不随读者改变，需要补的信息应继续调查。

如果还解释不清，回到相应材料改写自己的简报，再试一次。参考简报可供比较，不替代个人创作或课堂试学。
