# 第一章材料包：AI 辅助阅读与短篇表达

> 状态：review
> 版本：0.8.0

为初次接触模型项目的读者，做一份有依据的短说明。与[第一章第 1.5 节](../../textbook/chapters/CH01.md)对应；材料 A 足以完成核心任务，材料 B 可按兴趣选用。

## 开始与完成

1. 阅读材料 A，自己确定一位读者和一个问题。
2. 填写任务说明，提供材料全文及来源，使用可用的 AI 对话服务或 Agent 起草。
3. 回到材料核查，完成一次有理由的修订。
4. 保存短说明、来源和实际工具信息，并独立解释自己的选择。

建议约 400—600 字，可采用一页简报形式。无需前期作品、模型下载或 OpenDipper 访问；工具暂不可用时先分析参考成果，再补实际 AI 创作。具体准备见 [setup.md](setup.md)。

## 可选的生态观察

可进入 [OpenDipper 开源星系](https://www.x-lab.info/open-dipper/#ecosystem)，选择模型星系并搜索 `deepseek-ai/DeepSeek-R1`，核对项目身份，查看关系与来源。教材快照取得于 2026-10-30；实时界面和数据可能变化。图中的无向关联不能单独说明派生方向或性能优劣。

用教材卡片分析时注明“教材观察”；亲自操作后再补充实际日期与来源。是否完成此拓展不影响核心任务。

## 自查与接续

检查对象、依据、读者理解和个人判断。可以保存本次作品继续改进；第二章提供独立材料制作项目画像，不要求沿用或提交本章短说明。
