# 第一章材料包：一页有依据的项目研究简报

> 状态：review
> 版本：0.7.1

给一位尚不了解 DeepSeek-R1 的同学，做一页研究简报。使用 DeepSeek 网页端起草，在自己熟悉的文档工具中修订、保存。本包与[第一章正文](../../textbook/chapters/CH01.md)对应；正文第 1.7 节安排综合实践，核心材料、例题和反馈可直接阅读，下载是离线备份的选择。

## 完成任务的四个步骤

1. 想好读者与一个问题，先自己阅读材料 A、B。
2. 将读者、问题和两张材料卡填入任务说明，粘贴到 DeepSeek 网页对话中。
3. 读初稿，回到材料核对，完成一次有理由的修改。
4. 保存简报与来源，再独立解释自己的选择。需要时查看参考例子。

没有准备好 AI 账号时，可先做材料阅读和手工提纲，之后补做 AI 起草；无需安装 DSH、下载模型或注册 AtomGit。网页接入说明见 [setup.md](setup.md)。

## 网页操作参考

以下界面路线在 2026-10-30 核对；产品更新后可按“选对象—看关系—读说明—找来源”继续观察。先打开 [OpenDipper 开源星系](https://www.x-lab.info/open-dipper/#ecosystem)。

1. 选择“模型星系”，搜索 `deepseek-ai/DeepSeek-R1`。
2. 选择名称恰为 `DeepSeek-R1`、发布账号为 `deepseek-ai` 的结果，打开项目档案。
3. 在“关系与关注筛选”中保持“包含推断关联”关闭，查看“关系”页签，点击“只看关联”。
4. 找到与 `unsloth/DeepSeek-R1-GGUF` 的“模型派生关联”，点“解释关系”，再通过“项目主页”或“查看来源”核对公开材料。按无向关系展示时，不从连线推定派生方向。

若无法访问，使用教材截图和材料 B 完成分析，注明引用教材观察。亲自操作后再补充实际日期与来源。

从 [DeepSeek 官网](https://www.deepseek.com/)进入自己可用的网页会话，将任务说明中的读者与问题填好，并粘贴材料全文、来源和日期。取得初稿后，逐句对照材料，完成修改，再复制到自己的文档保存。记录实际服务名称和日期；只有界面明确显示时才记录模型标识，不根据研究对象 R1 推测后台模型。

## 自查与后续学习

留下一页简报及来源、一次修改与理由、一个后续问题；能说明模型项目与聊天服务的区别。第二章将以 OpenDipper 为完整项目建立档案，依据新材料修订简报；第三章进一步落实选定材料的复用条件，并回应具体读者需要。请保留各阶段版本，让同一份作品的变化可以解释。

本阶段成果服务于全书“科技研究与咨询：开源生态专题”实践，逐步发展为“开源生态专题研究报告”及“开源生态研究展示”，作为一个学习者项目在 AtomGit 开放维护。研究对象、AI 辅助研究方法与成果开放发布分别说明。
