# 第一章材料包：一页有依据的项目研究简报

> 状态：review
> 版本：0.3.0

给一位尚不了解 DeepSeek-R1 的同学，做一页研究简报。使用 DeepSeek 网页端起草，在自己熟悉的文档工具中修订、保存。本包与[第一章正文](../../textbook/chapters/CH01.md)对应；正文已提供完整材料与步骤，下载是离线备份的选择。

## 从这里开始

1. 想好读者与一个问题，先自己阅读材料 A、B。
2. 将读者、问题和两张材料卡填入任务说明，粘贴到 DeepSeek 网页对话中。
3. 读初稿，回到材料核对，完成一次有理由的修改。
4. 保存简报与来源，再独立解释自己的选择。需要时查看参考例子。

没有准备好 AI 账号时，可先做材料阅读和手工提纲，之后补做 AI 起草；无需安装 DSH、下载模型或注册 AtomGit。网页接入说明见 [setup.md](setup.md)。

## 可以带走的材料

| 文件 | 用途 |
| --- | --- |
| [材料 A](materials/source-a.md) | R1 项目的中文阅读卡，含固定来源 |
| [材料 B](materials/source-b.md) | OD 中的项目身份、关系与下一步问题 |
| [任务说明](prompt.txt) | 与正文完全一致；填读者、问题，再粘贴两张卡 |
| [个人记录](work/record.md) | 可选支架；正文已有的信息不用重复填写 |
| [参考简报](examples/guide-reference.md) | 课程编写者示例，先完成自己的初稿再对照 |
| [修订与自查参考](examples/check-reference.md) | 看懂一次具体修改及其理由 |

下载得到 `ch01` 文件夹，普通文档工具即可阅读其中的文字文件。参考简报存放在 examples 中，不冒充你的作品；你可以自行命名和保存成果。材料卡、提示词和参考例子均为课程编写者整理，未冒充 DeepSeek 真实会话或学生试学记录。

## 做到哪里，就可以继续

留下一页简报及来源、一次修改与理由、一个后续问题；能说明模型项目与聊天服务的区别。请保留这份作品：第二章会回到原始项目材料核对其中的一句话，并引入 DSH 作为第二个阅读对象。
