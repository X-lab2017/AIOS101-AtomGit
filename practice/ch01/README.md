# 第一章材料包：做一页 DSH 项目导览

> 状态：review
> 版本：0.2.0

本材料包配合第一章使用。两份短材料、同一份任务说明、一份空白记录和两份参考例子，帮助你从阅读走到一件可检查的作品。不要求手写代码。

## 使用顺序

下载本页提供的 ZIP 材料包并解压，得到 `my-ai-observatory` 文件夹。ZIP 是把多个文件收在一起的压缩包；请先展开，再在普通文件夹里操作。

1. 阅读下面的准备说明，确认已有可用的 AI 工具。
2. 打开 `materials/source-a.md` 与 `materials/source-b.md`，先自己读一遍。
3. 按第一章把 `prompt.txt` 中的说明发给工具；若用普通聊天工具，按正文调整为手工保存。
4. 打开并检查自己的初稿，填写 `work/record.md`。需要时再看参考例子。

生成的 `work/guide-v1.md` 应由你在练习中创建，材料包没有预先放入一份冒充成果的文件。

加上本说明，共 8 个文件。在线链接会打开课程仓库中的正本；下载包可以在本地直接打开。

## 准备条件

阅读可用手机；解压、选择工作区和保存作品更适合在电脑上操作。需要能够打开、编辑并保存文字文件的编辑器。Markdown 文档可按纯文本阅读，不必先学会排版语法。

推荐使用已经接通模型的 DSH。尚未准备好时，先读 [setup.md](setup.md)，从官方入口核对你使用的版本。普通 AI 聊天工具也能练习有依据的起草与核验，但文件需要自己保存，并据实记录执行方式。若暂无任何可用 AI 入口，先阅读与检查例子，AI 创作任务暂记未完成。

本包没有账号、密钥或额度，也不会自动连接 DSH 与 AtomGit。教学方应在开课前验证可用入口和资源条件。

参考例子由课程编写过程使用 AI 辅助起草并核对材料，不是学生提交，不是 DSH 生成记录，也没有经过真人试学。当前为内容评审稿。
