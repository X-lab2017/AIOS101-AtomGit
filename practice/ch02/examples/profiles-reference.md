# 编写者参考：DSH 项目画像

**例 2-3　一份面向初学者的 DSH 项目画像。**以下依据材料 D 的两个来源编写，为教材示范，不是实际运行、学生作品或社区贡献记录。

| 画像内容 | 参考记录 |
| --- | --- |
| 项目身份 | `deepseek-ai/deepseek-harness`，DSH 智能体框架 |
| 为谁解决什么问题 | 面向希望组织和扩展智能体功能的人，提供框架与插件方式；具体使用适配仍需结合任务判断 |
| 提供什么成果 | 程序源码、Web 界面启动说明，以及使用、开发、架构文档入口（D1—D2） |
| 我的阅读问题 | 尚未准备编程的学习者，可以从哪里了解和参与这个项目？ |
| 选择的材料 | README 帮助把握项目与文档入口；贡献指南帮助了解参与方式。两者分别回答“是什么”和“怎样参与” |
| 当前范围与协作 | 该快照处于开发者预览；贡献指南列出问题反馈、文章指南与答疑等方式，暂不接收外部 PR（D3—D4） |
| 我的判断 | 可以先阅读文档并整理不清楚的术语，再依据当前指南决定是否形成反馈；这是一项参与设想，尚未发生贡献 |
| 还需查什么 | 哪一项真实文档问题值得改进，是否已有讨论，现行规则是否变化？ |
| 来源与阅读方式 | 文献[8][10]，同一固定提交 `f3803c9…` 的贡献指南与中文 README；本例使用教材材料，未实际启动软件 |

画像用一个具体问题连接目的、材料与协作，没有把安装说明当作已经运行，也没有把建议当作社区采纳。使用 R1 材料时，协作规则可能暂缺，可以明确保留待查项；使用 OD 时，则应根据相应快照说明数据与示例范围。画像的价值在于组织认识和支持继续查证。
