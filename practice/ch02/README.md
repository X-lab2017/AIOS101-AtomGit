# 第二章材料包：打开一个项目

> 状态：review
> 版本：0.2.0

本章为 DeepSeek-R1 模型与 DeepSeek Harness 工具建立简明档案。只需浏览与编辑文字；不要求安装、下载模型、调用 AI 或发布社区内容。

## 开始使用

1. 下载 ZIP 并解压，得到 `ch02` 文件夹。
2. 将整个 `ch02` 放进第一章的 `my-ai-observatory`，保留既有材料和作品。若已经有同名文件夹，先改名或比较内容，不覆盖已填写的记录。
3. 从 [sources.md](sources.md) 选择材料，边阅读边填写 [项目档案](work/project-profiles.md)。
4. 在 [问题记录](work/questions.md) 中写一个值得继续探究的小问题；需要时再看参考例子。

加上本说明，共 7 个文件。包内链接可在本地打开；从网站查看单个文件会进入课程仓库的对应正本。

## 怎样判断完成

两份档案都应包含对象全名、有位置和日期的来源、项目说明、自己的阅读观察与未验证部分。再留一个具体问题，说明下一步需要什么证据。篇幅不设硬性字数；能让别人找到依据，比堆积材料更有用。

课程摘记不能代替自己的原站访问记录。暂时只能阅读摘记时，标记“材料研读完成，原站复核待做”。网页有介绍，不表示本地运行已经成功；本包也没有预填任何学生运行结果。
