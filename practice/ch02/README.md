# 第二章材料包：打开一个项目

> 状态：review
> 版本：0.3.0

本章以 R1 为主案例，以 DSH 作简短对照。目标是从公开材料形成理解，并继续完善第一章研究简报。学生可访问 GitHub、Hugging Face、AtomGit；只需浏览器与文档工具，无需下载模型或安装 DSH。

## 开始探索

1. 将本包保存在自己的研究项目中，与第一章简报并列；保留已填写文件的旧版本。
2. 先读 [来源导航](sources.md)，打开 OD 开源星系，搜索完整模型名称 `DeepSeek-R1`，核对发布者与对象类型。读取选中对象的关系说明，再通过其原始主页入口进入模型材料。没有相应记录时，直接使用来源导航继续阅读，并记录本次查阅条件。
3. 在 GitHub 阅读固定 R1 README 的 Introduction、Model Downloads 和 Distillation；在 Hugging Face 查看文件目录。用页面查找定位标题，不需要下载模型。
4. 依据 [材料卡](materials/reading-cards.md)，填写 [项目档案](work/project-profiles.md)。它包含一个主项目与 DSH 短对照，不要求两篇同等篇幅报告。
5. 在 [问题记录](work/questions.md) 留下下一问，修订简报的一句话；需要时再看 [参考档案](examples/profiles-reference.md) 与 [自查反馈](examples/self-check.md)。

这些文件可用普通文本编辑器打开，也可以复制栏目到自己熟悉的文档工具。AtomGit 在本章可用于保存个人研究材料；本章不要求发布、提交社区帖子或向上游贡献。

## AI 辅助阅读

教材 2.6 的提示词可以配合材料卡使用。请给出具体材料，并回到原文定位；最终用自己的话解释一个发现。无需把私人材料或账号信息提供给 AI。

## 完成标准

另一位读者能看懂主对象和问题，找到两处材料，理解一项关系解释，并看到一次有理由的简报修订及下一问。DSH 对照保留 README、贡献指南与许可入口，供第三章继续阅读。原站查阅日期由学生按实际情况填写；本包不预填任何运行或学生反馈。

## 内容与打印版

核心材料、例题和六题反馈都已包含在教材正文，纸面读者可以独立完成材料分析。本包只补充入口、操作支持和空白模板。章节 PDF 单独交付，网页与 PDF 使用同一份教材正本。
