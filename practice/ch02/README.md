# 第二章实践：读懂一个完整项目

> 状态：review
> 版本：0.4.1

对应教材 CH02 0.4.1。第一章从给定材料形成一页简报；本章以 OpenDipper 为主对象，自己选择问题、材料和解释方式。

1. 阅读 [材料卡](materials/reading-cards.md) 与 [来源导航](sources.md)，说明目的、成果、材料和协作。
2. 在 [项目档案](work/project-profiles.md) 写下主对象、两类材料及选择理由；在 R1、DSH 或本教材中选一个做短对照。
3. 在 [问题与修订](work/questions.md) 记录第一章简报的一次实际修改，以及下一步问题。
4. 对照 [参考档案](examples/profiles-reference.md) 和 [自查](examples/self-check.md)，完善自己的解释。

浏览器与文本编辑工具即可；核心任务不要求编程、安装、付费或对外提交。材料卡可独立用于纸面学习。实际访问和引用教材观察要分开记录，AI 整理不能替代自己的材料选择与核对。

完成物：一份主项目档案、一段短对照、一项有理由的修订与一个研究问题。把它们作为第一章作品的材料积累，后续与报告及动态页面一起进入自己的 AtomGit 项目；不需要把上游仓库完整复制进作业。

本阶段成果服务于全书“科技研究与咨询：开源生态专题”实践，逐步发展为“开源生态专题研究报告”及“开源生态研究展示”，作为一个学习者项目在 AtomGit 开放维护。研究对象、AI 辅助研究方法与成果开放发布分别说明。

## 与第三章衔接

本章主要修订项目认识与证据判断；下一章沿用这份简报及档案，落实一项材料的复用处理，并完成一次面向读者的改进。来源记录可以复用，新增内容集中说明本次用途和变化。
