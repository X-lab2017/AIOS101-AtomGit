# 第二章材料包：制作一份项目画像

> 状态：published
> 版本：0.5.0

对应[第二章第 2.5 节](../../textbook/chapters/CH02.md)。用目的、成果、材料和协作四个方面介绍一个项目，依据本包即可开始，无需第一章作品。

## 选择一种起步材料

- DSH 软件工具：材料 D，中文 README 与贡献指南。
- R1 模型：材料 E 及项目说明，未提供的协作信息可以列为待查。
- OpenDipper 数据研究项目：材料 A—C，README、材料说明与参与入口。

也可选择材料条件相当的其他项目。来源、版本与实际观察如实记录；学习知识有前置，任务文件不依赖前章。

## 完成任务

1. 从[阅读卡](materials/reading-cards.md)与[来源导航](sources.md)选择一个对象和一个阅读问题。
2. 组织身份、目的、成果、材料与协作；说明两类材料怎样帮助回答问题。
3. 保留来源与一个待解问题，能够解释材料选择。
4. 对照[参考画像](examples/profiles-reference.md)和[自查](examples/self-check.md)改善表达。

[画像支架](work/project-profiles.md)和[判断记录](work/questions.md)按需使用，已有内容不重复填写。成果可用一至两页图文或表格表达，重在解释清楚。AI 可以帮助翻译与整理，关键判断需要自己核对。

## 完成后的选择

可以继续修订画像，也可以在第三章使用新的材料完成复用与改进。另一类型项目的短对照为拓展，不要求修改第一章简报，也不要求安装工具或向社区提交内容。
