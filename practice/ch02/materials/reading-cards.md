# 四张阅读材料卡

整理日期：2026-10-29；版本：0.2.1。以下为课程编写者依据已阅读的官方材料整理的转述，不是完整原文、软件运行记录或学生访问证明。原始地址与版本见 [来源导航](../sources.md)。

## R-A · 模型 README

来源位置：Introduction、Model Downloads、How to Run Locally、License。

- 作者在简介中介绍 DeepSeek-R1 与 DeepSeek-R1-Zero。
- 下载区分别列出这些模型，以及名称带 Distill 的其他模型，链接指向相应 Hugging Face 页面。不能把所有条目记成同一个模型。
- 本地运行区对 R1 模型提供进一步文档入口，对 Distill 模型另列说明。找到说明不等于已满足自己的运行条件。
- 文末有许可入口。这里只登记位置，不替所有模型变体和服务作统一授权判断。

可以形成的阅读记录：“我在 R1 README 的模型下载小节找到 DeepSeek-R1 对应链接。”它不能证明模型已经下载或运行。

## R-B · 模型文件目录

来源位置：固定版本的 Files 文件列表。

- 文件列表中有 README.md、config.json，以及以 model- 开头、以 .safetensors 结尾的模型权重分片。
- 目录观察可以帮助区分说明文件、配置与模型文件；本章没有下载或加载权重。

待继续探究：“如果未来要运行某个模型，应到哪里确认所需的软件和硬件条件？”无需在本章立刻安装。

## D-A · DSH 中文 README

来源位置：开头、“开发者预览”、“社区与支持”。

- 开头把 DeepSeek Harness 介绍为 DeepSeek 开发的开源智能体框架，并提供进一步文档的入口。
- 此版说明处于开发者预览，后续变化可能破坏兼容性；教程与实际版本可能需要对照。
- 社区与支持部分指向 GitHub Discussions，供反馈或问题报告使用。

可以记录项目自述，但不能据此填写“我已接通模型”“我的文件任务已成功”。

## D-B · DSH 中文贡献指南

来源位置：开头说明和参与方式列表。

- 该版本说明暂不接收外部 PR（请求审阅并合入修改的方式）。
- 同时列出讨论反馈、插件分享、文章与操作指南、回答问题等参与途径。

一个合理的待验证判断：“一份面向新手的使用指南可能有帮助。”还需明确读者需求并检查效果；这不是“项目已经认可我的指南”。

## 说明、观察与推断

“作者这样说”有材料来源；“我打开文件并读到这一段”是阅读观察；“我的电脑能运行”“我的指南一定有用”需要另外的证据。记录时写清动作、对象和条件，比只写“已验证”更准确。
