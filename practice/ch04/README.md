# 第四章材料包：比较学习结果，解释适用条件

> 状态：review
> 版本：0.4.0

本包可独立使用，只需纸笔与计算器，也可用表格或 AI 辅助。无需前章作品、账号或观察站。全部字数与时间都是教学合成数据，见 [来源说明](sources.md)。

## 核心任务

1. 读 [训练卡](materials/training.md)，用 100→28、200→63、300→84 比较 a＝20、30、40，保存误差与选择理由。
2. 固定参数，再读 [新样本任务](materials/new-samples.md)，写下 D/E/F 的预测。
3. 打开 [核对卡](materials/check-values.md)计算误差。若已经看过正文答案，记录为复算。
4. 用自己的话解释最后一个情境为何难以只靠字数预测，并提出一种需补充的信息。
5. 对照 [参考计算](examples/reference.md)与[自查反馈](examples/self-check.md)修订说明。

把结果写在[实验记录](work/experiment-record.md)或纸上。应有一条完整算式、带条件的参数选择、新样本预测与误差、一项边界解释。正文中的 30/60/90 是前置例题，28/63/84 才是本次独立实践的训练值；两轮分别记录，不混算。

这些教学时间不用于给真实文档添加阅读时长。完成本章意味着能够解释如何比较与检查，不要求制作网站或公开提交。
