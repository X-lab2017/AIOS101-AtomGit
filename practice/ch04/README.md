# 第四章材料包：亲手选一次参数

> 状态：review
> 版本：0.3.0

只需纸笔和计算器。全部字数与秒数是教学合成数据，不是真人测量；来源与构造见 [sources.md](sources.md)。将 ch04 放入观察站，更新前保留自己的旧记录。

## 按这个顺序做

1. 读 [训练卡](materials/training.md) 的 A/B/C，算三组候选参数的误差，选一个。
2. 打开 [新样本任务](materials/new-samples.md)，先写 D/E/F 的预测。
3. 再打开 [核对卡](materials/check-values.md)，算误差。答案已看过也可以复算，不用假装盲测。
4. 回训练卡，换一组不整齐的训练值再选一次参数，体会没有零误差也能比较。
5. 对照 [参考计算](examples/reference.md) 和 [自查反馈](examples/self-check.md)，解释 B/F 同字数为什么需要额外信息。

所有结果放在一份 [观察记录](work/experiment-record.md)，或者一张纸上。不要把教学时间写进真实导览；本章成果是你能够解释“如何选参数，如何检查新情况”，不要求另写免责声明。

完成时应有一条完整算式、参数选择、新样本预测与误差、对遗漏特征的解释。材料包八个文件均用于这个实验，没有预填的学习者结果。
