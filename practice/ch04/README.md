# 第四章材料包：模型怎样学会本领

> 状态：review
> 版本：0.2.0

用纸笔和计算器，为一页导览试做一个阅读时间估计规则。你会用一组例子选择参数，再把规则固定下来，用没有参与选择的新例子检查它。本练习不需要编程、安装软件、注册账户或调用模型。

**本包所有字数与秒数都是课程设计的教学数据，不是真人测量，不是 DSH 或 DeepSeek 的性能评测。** 我们练习的是怎样学习和检验，不是在寻找人人通用的阅读速度。数据来源和适用边界见 [sources.md](sources.md)。

## 开始使用

1. 下载材料包并解压，得到 `ch04` 文件夹。把它放在自己的观察站文件夹里，与 `ch02`、`ch03` 并列；已有同名文件夹时先备份，不覆盖已填写的记录。
2. 准备一张纸、一支笔和可选的计算器。`.md` 是普通文本文件，可以用文本编辑器打开；不需要专门的 Markdown 软件。也可以把表格画在纸上。
3. 打开 [观察记录](work/experiment-record.md)，先填写你实际采用的方式。亲手计算、只读参考解、与同伴讨论是不同活动，按实际情况记录。
4. 暂时不要打开“核对卡”和“参考解”。先完成预测，再核对答案，才能保留一次没有看答案的检查。

## 约 20 分钟的核心路径

| 顺序 | 做什么 | 留下什么 |
| --- | --- | --- |
| 约 3 分钟 | 读 [训练卡](materials/training.md)，认清字数、秒数和参数 | 用自己的话解释规则 |
| 约 6 分钟 | 分别试每百字 20、30、40 秒，算误差并选择参数 | 三组预测、误差与选择理由 |
| 约 3 分钟 | 打开 [新样本任务](materials/new-samples.md)，固定参数，写 D、E、F 的预测 | 看答案前的参数和预测 |
| 约 4 分钟 | 再打开 [核对卡](materials/check-values.md)，计算误差 | 新样本结果与一个局限 |
| 约 4 分钟 | 对照 [自查反馈](examples/self-check.md)，写 [导览说明](work/guide-note.md) | 观察记录、个人解释、适用边界 |

时间只是学习安排建议，不是实测学习时长。卡住时可以看 [参考解](examples/reference.md)，然后如实写“参考解后完成”；不必假装独立算对。若已经在正文看过新样本答案，也请注明。本包仍可用于复算和理解，但不能再把这次过程称为未见答案的独立检验。

## 怎样判断完成

能展示至少一组完整的“字数 → 预测 → 对照目标 → 误差”计算，说明参数怎样选出、哪些样本没有参与选择，并用自己的话解释为什么旧样本误差小不等于所有新情况都可靠。最后给已有导览补一句适用范围或“尚未实际测量”的说明；不需要新建观察站，也不要把教学秒数写成真实读者的承诺。

保留 `work/experiment-record.md` 与 `work/guide-note.md`，或纸面记录的清晰照片。公开发布、提供个人阅读速度、邀请同伴接受测量，都不是完成要求。
