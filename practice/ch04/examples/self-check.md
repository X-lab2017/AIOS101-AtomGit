# 自查与参考反馈

先自己回答，再读每题后面的反馈。不要求使用完全相同的句子。

## 1. 本例的样本、输入、参数和输出分别是什么？

参考：一行教学例子是一个样本；字数是输入；a 是每百字需要多少秒的可调数；预测秒数是输出。目标秒数用于比较，不是预测值本身。

如果把“字数”写成参数，回到训练卡看一看：本轮哪些数随每行变，哪个数由你选择后固定？

## 2. 训练误差为零，可以说“所有导览都能算准”吗？

不可以。它只描述这三个教学训练样本。对没参与调整的新例子需要另外检查，真实人群、语言、文章难度和阅读任务也可能不同。

## 3. D 低估 3 秒、E 高估 3 秒，平均绝对误差是否为零？

不是。先取差的大小，再求平均，得到 3 秒。不要把一正一负的差抵消后误称为平均绝对误差。

## 4. 看过 D、E 的答案后修改 a，再用 D、E 报告独立检查，哪里有问题？

D、E 已经影响了修改，不能继续冒充没参与调整的新样本。可以保留这轮改进记录，但下一次独立检查应使用另留的样本。为了理解而复算答案没有问题，问题是把复算记成未见答案的检验。

## 5. F 的误差大，是不是证明字数与阅读时间无关？

不是。本例仅说明只看字数的简单规则在这个设计情境中不够。不能用一行合成数据证明真实世界的关系或因果。可以提出增加信息、限定适用场景、收集真实反馈等后续想法，不能写成已经验证。

## 6. 这次练习是不是训练了 DeepSeek，或者测出了 DSH 的速度？

都不是。你调整的是纸面规则里的一个数，没有调用、训练或评测这些系统。它帮助理解“用例子调整”和“用留出例子检查”，不代表完整大模型训练过程。
