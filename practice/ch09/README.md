# 第九章材料包：让一个实际问题推动修订

> 状态：review
> 版本：0.2.0

## 带上自己的候选

将 `ch09` 放入观察站，按 [materials/README.md](materials/README.md) 放入第八章候选与第七章设计的副本，以及实际来源和附件。没有候选时先回第八章。本包不预填作品、运行结果或同伴反馈。

## 三处检查，一次改进

打开 [work/review.md](work/review.md)，依据自己的设计，实际做一项内容核验、一项使用检查和一项理解或效果检查。只保留有用记录。自己检查无法确认他人独立理解时，标记待验证。

找一个真实问题，自己修改或请 DSH 协助，另存 `work/artifact-revised.md`；名称已存在就换新名称。使用 DSH 时选择 `ch09` 为工作区，先填好 review.md，再在 [revise-prompt.txt](revise-prompt.txt) 中填写允许读取的来源路径后发送。不要直接发送未填的提示词。

复查同一问题并比较前后，记录条件是否变化。没有同伴不阻塞独立核验与修订；未进行真人试读就不声称读者验证通过。未发现真实问题时保留检查结果，修订目标待实际问题出现后补足。
