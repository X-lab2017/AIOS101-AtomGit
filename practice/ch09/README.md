# 第九章材料包：沿用户任务检验观察站

> 状态：review
> 版本：0.3.0

按 [materials/README.md](materials/README.md) 带入自己的观察站候选、设计和来源。先写一张不泄露路径的用户任务卡，再实际检查内容依据、使用路径与理解效果，在 [work/review.md](work/review.md) 留下最有用的结果。

选一个影响任务的真实问题，自己修改或填写 [revise-prompt.txt](revise-prompt.txt) 后交给 DSH。工作区为 ch09，修订另存 `work/station-revised.md`，不覆盖原候选。多页产品须保留目录结构并检查整条路径。

用相近条件复查，写清前后有什么变化。没有真人试读就不填读者验证；没有真实问题就保留核验，等待有依据的修订。最后留一种维护触发条件和一项可复用方法，不要求新建运营平台或公开发布。
