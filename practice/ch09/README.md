# 第九章材料包：评议并改进一份资源导览

> 状态：review
> 版本：0.4.0

本包独立提供 aie-book 来源卡、待改资源页和检查任务。无需第八章作品、编程、真人访谈或指定 AI 品牌。也可自愿带入自己的作品，但需同时提供相应来源和标准。

## 先检查，再修订

阅读[任务与标准](materials/README.md)、[来源卡](materials/reading-cards.md)，再打开[待改作品 V0](materials/resource-before.md)。V0 是课程构造的错误候选，不是上游原文、学生成果或某个模型的实际输出。

先标出具体位置、问题、影响和材料依据，确定修改顺序。可以自己改写，也可将材料与[修订提示](revise-prompt.txt)交给聊天工具、DSH 或其他合适工具，核实其意见后保留个人决定。不要覆盖 V0，将修订稿自行另存；本包不预填学习者作品。

## 按同一标准复查

打开新稿，按资源身份、入口用途与评价依据三项标准复查。走查“查看主题安排”和“回顾某章要点”两项任务；可联网时实际打开入口，不能联网时核对材料语义，将可达性单独标为待查。真人试读可选，没做就不填作已完成。

在[记录支架](work/review.md)写下最重要的修改、复查结果和一项维护触发条件。完成后再看[参考修订](examples/resource-after.md)与[参考反馈](examples/self-check.md)。核心成果是一份改进作品和简短说明，过程可以合并记录，不按条目或对话轮次评分。
