# 放入自己的待检验作品

这里不预置候选或设计，避免把作者材料误当作学习者成果。

1. 将第八章选定的作品副本命名为 candidate.md，放在本文件旁。
2. 将第七章实际设计说明副本命名为 design.md，放在本文件旁。
3. 带上候选实际引用的来源材料、图片或附件；移动后检查相对链接。默认示范可复制第八章 role-notes.md 和 project-guide.md，保留其来源说明。
4. 保留原件；第九章修订只保存为新的 work/artifact-revised.md。

如果用的是网页、音频等其他形式，保留能打开的实际作品，把 candidate.md 写成入口、使用方式及必要文字稿；不能只用一个不存在的文件名代替作品。
