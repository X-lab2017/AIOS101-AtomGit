# 本章任务与标准

给定用途：帮助第一次访问 aie-book 的同学识别资源性质，并按问题选择一个阅读入口。本章读者情境是课程设计，未做真实用户调查。

完成标准：

1. 资源身份准确，不把配套目录和摘要说成原书完整开源正文。
2. 入口与用途相符，说明为何读、读哪里及必要条件。
3. 评价依据可说明，区分来源核验、作者走查、AI 建议和真人试读。

任务走查：你想先了解这本书讨论哪些主题，从哪里开始？你想快速回顾某章要点，选哪种资源，使用时要注意什么？

先用同目录 reading-cards.md 核对 resource-before.md，再形成自己的修订。网络不可用不影响核心语义分析；外部链接可达性仍需有条件时实际检查。若使用自己的作品，请替换来源及适合的标准，不沿用不相关的卡片。
