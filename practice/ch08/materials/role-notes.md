# 阅读时区分几个角色

| 名称 | 在本章中的作用 |
| --- | --- |
| 模型 | 根据当前输入生成内容或行动请求 |
| 上下文 | 组织当前一轮可见的指令、材料及工具结果等信息 |
| 工具 | 提供读取或操作外部对象的接口 |
| 运行支持层（Harness） | 在模型周围组织上下文、工具、循环和约束 |
| 环境（Environment） | 系统读取或改变的外部对象及其状态，例如文件 |

这是帮助进入原书的简要说明，依据 B2—B4。实际系统的实现有所不同，不把概念表当成任何产品的运行保证。文件路径只是定位信息；内容需被实际读取并进入后续输入，才可能支持回答。
