## 它是什么

DeepSeek Harness（DSH）是 DeepSeek 开发的开源智能体框架，可以先理解为把模型与执行工具组织起来的软件基础。固定版 README 标为开发者预览，后续方法可能变化。

## 可以怎样用

使用指南介绍了读取、编辑工作区文件等能力。工作区是当前任务使用的文件位置。可以尝试围绕两份材料整理一页项目导览：取得材料，整理候选，保存文件后由人打开检查。这里是任务建议，不是成功记录。

## 开始前确认什么

需先确认服务与模型可用，添加并选中本次工作区。项目开源不表示全部模型调用永久免费。操作是否询问用户取决于权限策略，即哪些动作可以直接做、哪些需要确认的规则。
