# Agent 教材阅读卡

- **B1** 《深入理解 AI Agent：设计原理与工程实践》由李博杰及贡献者共同建设，仓库提供正文与相关学习入口。本章选择其第一章“AI Agent 入门”和第二章“上下文工程”的有关内容。
- **B2** 第一章用模型、上下文与工具解释现代 Agent 的基本组成：模型据当前信息生成内容或行动请求，上下文组织本轮可见的信息，工具提供观察或操作外部对象的接口。这是帮助理解工程分工的视角。
- **B3** 第一章进一步区分 Model、Harness 与 Environment：Model 承担模型侧的决策，Harness 是围绕模型组织上下文、工具、循环和约束的运行支持层；文件、网页等环境对象与系统交互，不能仅因可被访问就等同于上下文或模型自身。
- **B4** 第二章说明，上下文需要组织任务所需的指令、材料、历史与工具结果等信息。工具结果进入后续上下文，才可能影响后续生成；仅在提示中写了文件名，不等于文件内容已经被读取。

以上为课程依据固定版本 dbc046e 的原创归纳，不是上游全文或实际工具运行日志。链接见同包 sources.md。无需实时访问原站即可开始本章分析。
