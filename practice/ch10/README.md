# 第十章材料包：让观察站可以被找到和使用

> 状态：review
> 版本：0.2.0

带入第九章已经检查的观察站候选与必要附件。这个包提供平台操作卡和可选记录，不预填你的作品，也不要求重新建站。

## 先整理，再分享

1. 保留原候选。若采用单文件文档版，把一份交付副本命名为 `station.md`，准备同层的 `README.md`；有附件则保持正确相对路径。
2. README 写明服务谁、作品入口、开始条件和本版范围。来源与 AI 参与说明已有就链接过去。
3. 阅读 [AtomGit 浏览器操作卡](atomgit-web-guide.md)，进入原有仓库或创建自己的代码仓。先检查分享范围，再保存必要文件。
4. 从平台重新打开作品与提交历史，核对可访问性和版本。若有真实同伴，邀请他完成一个使用任务；自学者先自查。

已有作品说明可以直接容纳记录，无须另外填表。需要支架时用 [work/share-check.md](work/share-check.md)。完成后进入[第十一章](../../textbook/chapters/CH11.md)。

## 自学预设反馈

先回答再看下面内容。这些是作者设计的检查题，不能记成真人反馈。

- 上传 `index.html` 后只看到源文件，是否已经有可运行网站？**反馈：**没有。仓库保存和网站托管是两种能力，应提供真实部署入口或准确的下载使用方式。
- 私密仓库在作者电脑上正常打开，能否记“同伴已访问”？**反馈：**不能。先确认对方权限并实际验证，没做就保持待验证。
- 文件里有图片，移到新文件夹后图片消失。**反馈：**查相对路径和遗漏附件；不要只把电脑绝对路径换成另一个自己的目录。
