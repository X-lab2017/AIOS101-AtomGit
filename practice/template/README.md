# 我的 AI 开源项目观察站

> 状态：draft
> 版本：0.2.0

> 空白产品模板：复制后用自己的内容替换提示，未完成的内容如实标明。五块内容按需要生长，不要求一次填满。

## 你想从哪里开始

写一句给真实使用者的欢迎说明：这个观察站帮助谁完成什么，不要只写“课程作业”。

- 我想认识项目：[项目档案](project.md)。替换成项目名，并写一句用途与选择理由。
- 我想使用一件作品：[作品与使用说明](work.md)。替换成可辨认的作品名与实际入口，不只留占位标题。
- 我想继续探究：[观察与探究](observations.md)。连接自己确实完成的实验或阅读问题。

## 这版能做到哪里

用一句话写本版可走通的路径，例如“从项目卡看用途与来源，再打开入门作品并找到下一步”。链接指向真实内容；尚未完成的功能不伪装成可用入口。

## 看见改进与成长

- [核验与修订](verification.md)：什么问题怎样改变了作品。
- [反馈与协作](collaboration.md)：只放实际发生的交流和贡献。
- [个人技能与作品集](portfolio.md)：哪种方法有作品证据，换情境时还要重查什么。

## 来源与维护

记录观察日期、版本、使用条件与分享范围。写一种触发维护的变化及要重查的地方，例如官方条件变了，要同时检查项目卡与任务入口。不要放账号密钥或私人材料。
