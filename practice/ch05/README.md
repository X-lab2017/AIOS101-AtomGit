# 第五章材料包：观察材料怎样改变生成

> 状态：review
> 版本：0.3.0

为已有 DSH 导览增加一个可理解的任务示例。两份提示词只差一张本地任务卡，不重复练习安装条件。

## 有可用 AI 入口

1. 先写一句预测：增加任务卡可能改变什么？
2. 同一模型/模式，两个新会话分别运行 [提示词 A](prompt-a.txt) 和 [提示词 B](prompt-b.txt)。本任务只生成文字，不执行文件操作。
3. 在 [比较记录](work/comparison-record.md) 保留两份原始输出，圈出一处变化，追到新增材料。
4. 看 [自查反馈](examples/self-check.md)，修订一段可以留给导览的文字。没有差异或出现错误都如实记录。

尽量关闭额外检索；无法关闭或看不到设置时记明限制。无需为本练习付费或安装新工具。

## 暂未接入

做正文 5.1 的双背景续写，再读 [材料 A](materials/brief.md) 与 [任务卡 B](materials/guide.md)，圈出只能从任务卡得到的细节。自己写候选段落；活动记为“上下文演练”，两次真实输出待补。
