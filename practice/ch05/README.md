# 第五章材料包：让回答有据可查

> 状态：review
> 版本：0.2.0

围绕“新用户打开 DSH 网页后能否不做其他准备就直接输入并完成文件任务”比较材料条件。核心路径只需纸笔或文本编辑器；真实调用为可选拓展，不要求付费、安装或公开发布。

## 先后顺序

1. 解压得到 `ch05`，放入已有观察站，与 `ch04` 并列。有同名文件夹时先比较，保留自己填写的记录。
2. 先只读材料 A，在记录表留下初判；再加入材料 B，回答同一问题。保留两份答案，不覆盖。
3. 逐项核对身份、准备条件和实际完成情况，再审阅两份编写者构造的待审稿，最后查看反馈。
4. 为已有导览修改一句话，写明原句、新句和依据。没有导览时，可针对第一章参考导览提出建议，标明这是参考材料练习。

前几章已学过部分条件也没有关系；区分自己已知与本轮材料支持的范围。这是一项证据判断练习，不是未知事实盲测。

## 可选：实际模型调用

已有可用工具时，在两个新会话分别发送 prompt-a.txt 与 prompt-b.txt。固定同一模型、模式和可见设置；如果支持，关闭额外检索。不要将第一份回答、反馈或答案发到第二个会话。不能控制的设置如实记录，不能仅凭指令认定工具没有运行。

只需复制提示词中的材料，不必让工具读取含参考答案的整个目录。保存完整原始输入输出、实际模型名称、日期和可见工具记录；未显示的设置写未显示。若重试，先约定次数并保留两种条件的全部结果。

## 怎样判断完成

留下一个固定问题、两个材料条件、两份回答或判断、三处具体核对、一项局限和一次导览修订。纸面阅读、看反馈后演练、实际调用分开标注。没有调用时不要填写模型性能改善或运行成功。
