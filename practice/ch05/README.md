# 第五章材料包：改善材料组织，比较生成结果

> 状态：review
> 版本：0.4.0

本包独立提供全部材料，不需要第四章作品或项目安装。比较对象是 AIInfra 学习入口说明。固定版本和材料改写范围见[来源说明](sources.md)。

## 选择与条件相符的学习路径

**实际生成对照：**用同一个可用 AI 工具、同一个模型和尽可能相同的设置，在两个新对话中分别提交[提示 A](prompt-a.txt)与[提示 B](prompt-b.txt)。可用 DSH 或其他工具；本任务只生成文字，不需要文件写入权限或付费 API。关闭不需要的搜索、工具与记忆功能；无法关闭的项目在记录中说明。保留原始输入、输出、日期和可见版本，再比较一处变化与材料依据。

**纸面证据分析：**没有工具时，阅读[教学候选与反馈](examples/self-check.md)，逐条对照[材料 A](materials/brief.md)与[材料 B](materials/guide.md)，指出冲突、未知与有依据的内容，再写出自己的对照设计。这条路径完成机制与证据分析；真实生成目标仍需另行完成，不用编造输出。

## 比较什么

同一任务中只计划改变材料：A 为课程概览，B 条件增加目录线索。两份提示由[共同模板](prompt-template.txt)生成，指令完全相同。准确性、任务完成度和可用性分别判断，不预设 B 一定更好。

用[比较记录](work/comparison-record.md)保存判断。修订稿与原始输出分开；一次对照只说明本次条件下的表现。无需公开上传。
