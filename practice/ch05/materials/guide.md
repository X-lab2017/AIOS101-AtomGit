# 材料 B：补充的使用条件

本卡是课程对同一固定版本 Web UI 指南的转述，不是本次运行结果。条件 B 同时提供材料 A 与本卡。

- B1：指南从 Web UI 服务已经启动的状态开始；其模型配置部分介绍填写连接模型所需的设置。不能只根据页面打开就认定模型已经接通。
- B2：全新的 Web UI 需要添加并选中工作区。工作区是当前任务使用的文件位置；选中之前，会话输入框不可用。
- B3：指南描述智能体可以读取和编辑工作区文件、运行命令等；某项动作是否询问用户取决于权限策略。文档没有提供这位学习者的具体任务结果。
