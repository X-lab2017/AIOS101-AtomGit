# AI 开源项目观察站

> 状态：draft
> 版本：0.1.1

这是贯穿全课的项目实践载体。师生都建设观察站，共同采用基本结构，观察问题、作品形态和探索深度可以不同。

## 从最小观察站开始

从第一章的一页导览和一个本地文件夹开始。每章继续改进同一份作品，逐步加入来源、问题与使用说明；暂时不需要建网站或公开发布。

| 现在学到哪里 | 这次只做什么 | 材料入口 |
| --- | --- | --- |
| 第一章 | 起草、打开并核对一页 DSH 导览 | [第一章材料包](ch01/README.md) |
| 第二章 | 为 DSH 与 R1 建短档案，核对导览中的一句话 | [第二章材料包](ch02/README.md) |
| 第三章 | 沿用其中一项材料，补来源与使用说明 | [第三章材料包](ch03/README.md) |
| 第四章 | 用纸面实验理解模型学习，为导览补适用范围说明 | [第四章材料包](ch04/README.md) |
| 第五章 | 固定一个问题，对照材料并修订导览中的说法 | [第五章材料包](ch05/README.md) |

第一章解压后得到 `my-ai-observatory`；之后的 `ch02`、`ch03`、`ch04`、`ch05` 文件夹放在它里面。它们保存不同阶段的材料，不替换已经完成的作品。先下载当前章，后续需要时再取下一份。

## 五项逐步积累的内容

| 内容 | 回答的问题 |
| --- | --- |
| 项目档案 | 我在观察什么，材料来自哪里？ |
| 理解与探究 | 它怎样工作，我怎样知道？ |
| AI 创作 | 我能据此做出什么有用的成果？ |
| 开放协作 | 别人提出了什么，我怎样改进？ |
| 个人积累 | 我学会了什么，证据在哪里？ |

## 示范与模板

[查看示范项目](demo/README.md)：展示材料的组织方式，明确区分资料阅读与实操。

[全课实践模板](template/README.md)：需要扩展观察站时再取用。前五章已经有专用材料包，不必同时填写这套模板。之后可把作品整理到自己的 AtomGit 仓库；核心路径不依赖 DSH 与 AtomGit 自动连接。

## 怎样判断完成

作品应当帮助具体读者，关键判断有证据，至少完成一次真实核验和一次有依据的修订。记录自己作出的判断与贡献；同伴反馈、教师反馈、预设反馈和 AI 建议分别标明。

课程的 AtomGit 社区地址尚未配置。当前可下载章节材料包，在自己的空间实践；此页面没有自动创建账号、仓库或上传文件的功能。
