# 章节实践与作品资源

> 状态：review
> 版本：0.4.0

各章实践围绕本章的知识与能力展开，提供起步材料、任务要求和参考反馈。你可以从本章给定材料开始，不需要先交齐前章作品；必要的知识准备在各章说明。也可以选择延续值得继续探索的成果。

## 从前三章的独立任务开始

| 章节 | 核心输入与任务 | 材料入口 |
| --- | --- | --- |
| 第一章 | 使用项目说明材料 A，借助 AI 完成有依据的短说明；生态材料 B 选做 | [第一章材料包](ch01/README.md) |
| 第二章 | 从 DSH、R1、OD 给定材料或其他合适项目中选一个，制作项目画像 | [第二章材料包](ch02/README.md) |
| 第三章 | 使用公开写作建议、待改短文与预设读者反馈，改进写作贡献提示卡并说明复用 | [第三章材料包](ch03/README.md) |

下载本章材料即可开始阅读。参考成果是编写者示范，帮助理解要求；预设反馈用于练习，不能写成真实用户评价。实际使用 AI、访问原站或参与社区时，请保留自己的过程记录。

## 选择工具与材料

AI 创作从第一章开始。可以使用适合任务的 AI 或 Agent 工具，DSH 是可研究和选用的例子。教材解释共通方法，配套材料补充实际操作条件；工具不可用时可先阅读与分析，真实操作另行完成并如实标记。

OpenDipper 提供开源生态数据展示、观察入口与案例材料，可用于提出问题、补充证据。根据任务选择需要的数据，不必每章访问同一平台。本版以 AtomGit 示范版本管理与开放协作，课程尚未配置统一 AtomGit 教学空间。

## 从章节成果到个人作品

一份项目画像可以发展为研究报告，一组比较材料可以形成解释图或交互展示，一次文档改进可以成为社区贡献。你可以选择代表性成果继续打磨，也可以围绕新问题重新设计。综合创作的具体要求由教学设计明确。

[已有观察站示范](demo/README.md)与[早期模板](template/README.md)保留供选择参考，不是每章的共同任务，也不代表实际运行或真人反馈已经完成。

## 案例与作品库的预留方向

教材案例帮助学习分析方法，章节材料包支持独立实践，作品库用于分享和相互学习。后续可逐步设计开源软件项目、开源企业、开源模型、开发者等画像案例，以及研究报告、图解、交互展示和社区改进作品。具体案例与学生作品暂留设计空间；目前不提供自动提交或收集入口。

作品入库需经过内容整理、来源核验与分享授权。是否公开展示由学习者选择，不以公开展示或受欢迎程度代替课程评价。
