# OpenDipper 研究实践

> 状态：draft
> 版本：0.3.0

本课以 OpenDipper 为观测与研究工具，也把它作为真实项目学习。你的最终作品是一份专业开源研究报告及配套动态页面，在 AtomGit 作为同一个项目持续维护。下面按当前章节提供材料；后续章节仍保留部分以“观察站”命名的作品组织练习，可用于积累研究素材，不要求另建一个 OpenDipper。

## 从一页研究简报开始

从第一章的一页 R1 研究简报和自己熟悉的文档工具开始。逐步加入来源、问题与使用说明，再把已有档案、探究和作品连成可用的观察站路径；暂时不需要建网站或公开发布。

## 五项逐步积累的内容

| 内容 | 回答的问题 |
| --- | --- |
| 项目档案 | 我在观察什么，材料来自哪里？ |
| 理解与探究 | 它怎样工作，我怎样知道？ |
| AI 创作 | 我能据此做出什么有用的成果？ |
| 开放协作 | 别人提出了什么，我怎样改进？ |
| 个人积累 | 我学会了什么，证据在哪里？ |

## 示范与模板

[查看示范项目](demo/README.md)：从项目选择进入有来源的档案，打开可读导览，再找到下一步；这是作者内容产品示范，不是DSH实跑或真人反馈。

[全课实践模板](template/README.md)：需要扩展观察站时再取用。十二章已经有专用材料包，不必同时填写这套模板。之后可把作品整理到自己的 AtomGit 仓库；核心路径不依赖 DSH 与 AtomGit 自动连接。

## 怎样判断完成

作品应当帮助具体读者，关键判断有证据，至少完成一次真实核验和一次有依据的修订。记录自己作出的判断与贡献；同伴反馈、教师反馈、预设反馈和 AI 建议分别标明。

课程的 AtomGit 社区地址尚未配置。当前可下载章节材料包，在自己的空间实践；此页面没有自动创建账号、仓库或上传文件的功能。
