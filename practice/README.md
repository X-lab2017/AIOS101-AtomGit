# AI 开源项目观察站

> 状态：draft
> 版本：0.1.0

这是贯穿全课的项目实践载体。师生都建设观察站，共同采用基本结构，观察问题、作品形态和探索深度可以不同。

## 从最小观察站开始

先建立一个清楚的阅读首页，记录项目来源和想探究的问题。随着学习加入任务记录、作品、反馈和个人积累。第一轮只需完成一个小问题、一件作品和一轮有依据的修订。

## 五项逐步积累的内容

| 内容 | 回答的问题 |
| --- | --- |
| 项目档案 | 我在观察什么，材料来自哪里？ |
| 理解与探究 | 它怎样工作，我怎样知道？ |
| AI 创作 | 我能据此做出什么有用的成果？ |
| 开放协作 | 别人提出了什么，我怎样改进？ |
| 个人积累 | 我学会了什么，证据在哪里？ |

## 示范与模板

[查看示范项目](demo/README.md)：展示材料的组织方式，明确区分资料阅读与实操。

[使用实践模板](template/README.md)：复制到自己的 AtomGit 仓库，按章节逐步填写。模板是一组普通 Markdown 文件，可以通过浏览器编辑；核心路径不依赖 DSH 与 AtomGit 自动连接。

## 怎样判断完成

作品应当帮助具体读者，关键判断有证据，至少完成一次真实核验和一次有依据的修订。记录自己作出的判断与贡献；同伴反馈、教师反馈、预设反馈和 AI 建议分别标明。

课程的 AtomGit 社区地址尚未配置。当前可下载模板，在自己的空间实践；此页面没有自动创建账号、仓库或上传文件的功能。
