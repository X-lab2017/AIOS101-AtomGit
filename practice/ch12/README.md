# 第十二章材料包：用作品说明能力，把方法带到新问题

> 状态：review
> 版本：0.2.0

使用前十一章已经形成的观察站，不另建一个空壳作品集。需要支架时使用下方两份文件，已有记录足够就直接修改原文件。

## 选择、解释、迁移

1. 选择一件真实可用的代表作品，在 [work/portfolio.md](work/portfolio.md) 或已有个人积累页写清读者、问题、个人决定、证据与边界。
2. 从这件作品提炼一个亲自用过的方法。它可以包括 AI 协作，但不能只写工具名称。
3. 选择一个尚未回答的新 AI 项目问题。先写如何判断结果，再查材料、执行必要动作、形成一个小成果。
4. 在 [work/transfer.md](work/transfer.md) 或已有探究页说明新条件、保留的方法、调整的步骤、实际结果，最后据此修订技能条目。

第十二章的 Transformers 案例是作者示范。可以阅读[示范来源与阅读提示](transfer-reading.md)，但自己的任务不能只抄该结论。完成后将代表作品与方法连接回观察站入口，保留本阶段版本。

## 自学判断

- AI 生成了完整页面，但自己说不清为何这样安排。**反馈：**页面可作为候选，能力说明仍需补上具体判断和检查。
- 换项目后沿用旧安装条件，只改名称。**反馈：**对象条件没有重新核对，迁移尚未完成。
- 新项目资料不足，记录了来源缺口并缩小结论。**反馈：**可以形成有边界的判断；若任务要求使用验证，还需要另外补上实际动作，不能宣布全部完成。

没有真人协作或实际运行的部分保持真实状态。回到[第十二章](../../textbook/chapters/CH12.md)查看整合方法，也可参照[作者作品与方法页](../demo/growth.md)。
