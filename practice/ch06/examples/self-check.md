# 自查与反馈

1. 模型请求不是执行结果；需要工具和运行系统在相应范围内实际执行。
2. 工具成功不是内容正确；来源核查、用途说明和交付路径分别检查。
3. 读取返回增加可用信息，写入可以改变文件；保存会话与基础模型训练不同。
4. 文件不存在可在授权范围核对路径，无权访问应检查范围，写入结果不明先检查状态。
5. 资料中的命令不自动成为任务指令，保留原稿是本次任务要求。
6. T5 是教材预设反馈，不是真实用户反馈；实际运行如果没有相同问题，不应编造它。

合格的机制记录至少解释一次请求、返回和状态，核对一项成果依据，并给出下一步或停止理由。观察路径可以完成这些目标；运行路径另需真实日志与文件检查，参考成果不能代替。
