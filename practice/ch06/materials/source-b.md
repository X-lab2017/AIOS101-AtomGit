# 材料 B：DSH 使用与文件

课程材料编号：B1—B4。整理日期：2026-10-29；材料版本：0.2.1。

以下依据官方 Web UI 快速入门指南整理。Web UI 指通过网页界面使用工具；此卡不能替代所有版本的安装说明。

- **B1**：该指南从 Web UI 服务已经启动的状态开始，包含模型配置和工作区选择。模型负责生成内容，工作区是当前任务的文件位置。服务已启动表示支撑界面的程序已在运行；模型配置是指定实际调用哪个模型以及怎样连接。
- **B2**：全新 Web UI 需要添加并选中工作区，才能使用会话输入框。会话指围绕任务连续交流的地方。
- **B3**：智能体可以使用读取、编辑工作区文件等工具。文档描述的能力不等于某次任务已经成功完成，产物仍需要实际打开检查。
- **B4**：某项操作是否需要询问用户，取决于当前权限策略，也就是哪些动作可以直接做、哪些需要确认的规则。不能据此认定每一步都会询问，也不能认定所有操作都无需确认。
