为前章已有导览增加“一个可以尝试的任务”，保留原稿、来源与使用说明。包内参考导览继承前章正确内容，不故意重新植入旧错误。

## 路径一：追踪实际 DSH 任务

前提是第一章已有可用环境，或教学方已核实工具、模型与额度。本包不要求新安装或付费。

1. 保留自己的旧作品。将 ch06 文件夹本身选作工作区；用已核验导览的副本替换 [参考原稿](materials/guide-before.md)，或直接使用参考稿。
2. 确认 work/guide-candidate.md 不存在；已有时选择一个新名字并同步修改 [提示词](prompt.txt)。只用本包公开材料，不开放整个个人目录。
3. 发送提示词；已有第五章选好的候选段落时附在末尾，否则按材料起草。候选中的第五章编号不沿用，按本包来源卡重核。观察一次读取请求与返回，打开新文件，圈出新增段落。
4. 给出一个真实阅读反馈；只授权修改本次新稿对应段落。再次打开，保存一处前后变化。
5. 在 [任务记录](work/task-record.md) 记三处关键事件，不必抄全部会话。对照 [反馈](examples/self-check.md)。

本任务只读 [材料 A](materials/source-a.md)、[材料 B](materials/source-b.md) 和导览原稿，创建/读回一个新稿，后续按人的明确反馈修改新稿。拒绝无关安装、删除与发布。提示词不等于技术隔离，权限配置与官方安全说明见 [来源](sources.md)。

## 路径二：尚未接入

使用 [机制卡](examples/mechanism-cards.md) 分角色演练：提出请求→手工取得文件→返回内容→起草与另存→提出反馈。遇到“未找到文件”时先决定下一步，随后再翻卡。

可以在同一份任务记录写自己的动作，标注“机制演练；DSH 实跑待补”。这里完成机制理解，不代替实际任务目标。第一章已有真实记录时，也可回看那次任务，缺少的环节以后补做。

包中不预置产物，不提供作者虚构的 DSH 日志。当前课程已核对文档与材料，尚未完成 DSH 操作实测与真人试学。
