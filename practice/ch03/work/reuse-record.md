# 一项材料的来源与复用记录

空白模板。填写真实情况；不适用就说明理由，未查明就写待确认。

## 对象与行为

- 我的作品名称、文件与具体位置：
- 外来材料的具体名称与范围：
- 原作者 / 权利人（保留原声明）：
- 原始链接、文件及版本：
- 我实际阅读的日期：
- 我读的是原站、离线许可副本，还是课程摘记：
- 本次实际或计划行为（链接 / 复制 / 翻译 / 改写 / 其他）：
- 当前是计划，还是已经实施：

## 条件与处理

- 适用许可的名称、版本和原文位置：
- 为什么认为该声明适用于这项材料：
- 是否有第三方例外或另行说明：
- 与本次行为有关的允许事项：
- 需要保留或履行的条件及原文位置：
- 实际保留了哪些声明，位于什么文件：
- 我做了哪些修改，哪些是自己的新增内容：
- 仍待确认的条件，以及下一步：

## 交付状态

- 已核对并完成的处理：
- 尚未核对或暂不纳入分享的材料：
- AI 参与了什么，我亲自检查了什么：
- 实际分享 / 反馈情况（尚未发生就如实写）：
