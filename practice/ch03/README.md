# 第三章材料包：开放的力量

> 状态：review
> 版本：0.2.2

为已有观察站补一份来源与使用说明。核心练习只需阅读和编辑文字，不要求安装、注册、发帖或提交 PR，也不替学习者自动选择整站许可证。

## 开始使用

1. 下载 ZIP，解压得到 `ch03` 文件夹，放入自己的观察站，与 `ch02` 并列。
2. 已有同名文件夹时先备份、比较，不覆盖自己填写的材料。
3. 第一次可以选本包提供的 DSH 介绍，沿用第二章 README 来源，再读本包的完整 MIT 原文。若第一章的 R1 简报没有 DSH 段落，直接标明使用参考材料练习，不必补写一份 DSH 导览。也可选另一项真实材料；本章只处理一项。
4. 填写 [复用记录](work/reuse-record.md)，再把结论整理成给读者看的 [使用及署名说明](work/use-and-credit.md)。前者留查找依据，后者让别人知道如何接着使用，不必重复写长报告。

从观察站根文件夹看，两份记录分别在 `ch03/work/reuse-record.md` 与 `ch03/work/use-and-credit.md`。原声明在 `ch03/licenses/DSH-MIT.txt`。保存后，从自己的导览标明使用说明的位置，再实际打开核对。

## 先弄清一个边界

`licenses/DSH-MIT.txt` 只记录 DSH 对应原材料的 MIT 许可，不为整个材料包、你的观察站或所有 AI 输出统一授权。自己的新增内容由有权作出决定的人选择使用条件；第三方材料仍按各自说明处理。

复制或改编需要保留声明的材料时，让声明随相应材料一起交付，写清它对应什么。不要把原版权人换成自己的名字。

## 怎样判断完成

至少一项材料能从作品中的具体位置追到原始来源，说明实际使用方式、许可依据、应保留内容、已经做出的处理和未确认项。来源说明不以公开发布为完成条件。

原站暂时不可访问时，可读摘记及包内原许可，注明自己实际读的是课程材料或离线副本，不记成已经访问原站。正文任务与来源条件仍需按所选材料核对。尚未决定的使用条件可保留，但要写清暂不分享、补查或替换的处理安排。

前三章收束时，从初稿挑一句话，说明找到了什么依据、怎样改进、后来者到哪里找使用条件。准备说明不等于已经发生社区贡献；读者反馈待实际发生后再记录。
