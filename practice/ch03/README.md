# 第三章材料包：复用材料，改进读者说明

> 状态：review
> 版本：0.4.0

对应[第三章第 3.5 节](../../textbook/chapters/CH03.md)。用开放指南中的写作贡献建议，制作一张适合初学者的提示卡。核心任务的材料、待改说明和预设反馈在本包与正文中齐全，不需要前两章作品。

## 从给定说明开始

待改说明（编写者为练习拟写）：“不会写代码也可以参与开源。打开仓库，写点文档，把修改提交就行。”

预设反馈：“我知道不会编程也能参与，但还不清楚可以先改哪一处、需要先读什么，以及改完后该怎样交流。”

1. 阅读[材料 A](materials/reading-cards.md)与[来源导航](sources.md)，确定使用哪些写作建议。
2. 改写成约 120—200 字的提示卡，说明具体起点、参与规则和交流方式。
3. 保留作者、来源、许可、修改与相关说明，解释一次改进的理由。
4. 对照[参考成果](examples/reuse-reference.md)与[自查反馈](examples/self-check.md)完善作品。

可借助 AI 整理与比较表达，自己负责核查和解释。也可选自己的材料与作品完成等量任务，前章成果仅为可选。

## 纸面与配套材料

正文保留材料 A、B、完整例题、给定任务和六题反馈。包内的 [CC BY 4.0](licenses/CC-BY-4.0.txt) 与 [DSH MIT](licenses/DSH-MIT.txt) 分别对应所选原材料，不为整个包或学生作品统一授权。MIT 为拓展对照，不是核心提示卡必须使用的材料。

[复用与改进记录](work/reuse-record.md)保存核对依据，[读者说明](work/use-and-credit.md)帮助后来者阅读；可以合并到成果附记，无需重复填写。材料 B 的真实文档修订用于分析贡献与采纳，不是要求模仿提交。

## 完成标准

提示卡能帮助读者找到具体起点，引用与改写可以追查，作者能够解释一次变化。实际 AI 使用、预设反馈、真人试读、分享和采纳分别记录。本章可在本地完成，不要求发布网站或向社区发送练习内容。
