# 第三章实践：完善一份可接续的研究简报

> 状态：review
> 版本：0.3.0

对应教材第三章《开源的力量》。沿用前两章的简报与项目档案，完成一项材料复用、一次面向读者的改进及必要说明。成果服务于“科技研究与咨询：开源生态专题”，逐步支持专题研究报告和研究展示。

## 完成任务的四个步骤

1. 选择简报中实际使用的一项材料；也可用本包的 Open Source Guides 示例练习，并注明使用参考材料。
2. 阅读 [材料卡](materials/reading-cards.md) 和 [来源导航](sources.md)，在 [复用记录](work/reuse-record.md) 写明对象、用途、条件和处理。
3. 根据真实需要、自查或标明性质的预设反馈，完成一处改进，在记录中保留前后文字及理由。
4. 用 [读者说明](work/use-and-credit.md) 交代来源、改动、条件、AI 参与与未确认项；对照 [完整示例](examples/reuse-reference.md) 和 [自查反馈](examples/self-check.md)。

本章只需浏览器和文字编辑工具。下载后得到 ch03 文件夹，与此前材料并列保存；同名文件先比较再合并。你自己的简报可继续使用原文件名，保留前一版本。尚未实际访问原站时，注明使用课程阅读卡或离线副本。

## 纸面与在线材料

正文包含核心材料 A、B、完整例题、三章演进示范和六题反馈；本包提供实际填写位置、完整许可文本与可点击来源。许可文件分别为 [CC BY 4.0](licenses/CC-BY-4.0.txt) 和 [DSH MIT](licenses/DSH-MIT.txt)，它们对应所选原材料，不为整个包或你的作品统一授权。

核对记录用于保存依据，读者说明用于帮助后来者继续使用；无需把同一调查过程抄两遍。实际分享时，使说明与相应材料一起可取得，检查原文、许可和免责入口。

## 完成标准

同一份简报有一项可追查的材料处理、一次有理由的改进，以及简短可读的使用说明。自己仍待确认的材料有后续处理安排。只有实际发生过的访问、AI 使用、试读、提交和采纳，才写作个人经历；预设反馈可用于练习，但不写成同伴意见。

最终公开发布、AtomGit 操作和真实社区协作在后续推进，本章无需对外发帖。将本次结果与前两章放在一起，解释作品为什么变化、依靠什么依据、怎样帮助目标读者。
