## 一个可以继续探索的问题

DSH 说“完成”之后，我怎样确认它真的生成了所需文件？

可以设计一个很小的任务：用两份已获准使用的项目材料，制作一页导览。观察读取材料、生成内容、保存文件的实际过程，再亲自打开文件检查。
