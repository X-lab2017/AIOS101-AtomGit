# AI 开源项目观察站：从一个问题开始

> 状态：review
> 版本：0.2.0

想了解模型怎样形成能力，还是想看 AI 怎样协助处理文件？从下面选一个观察对象。本示范面向第一次接触开源 AI 项目的同学，帮助你找到项目、依据和可以继续使用的作品。

这是课程作者制作的可阅读产品示范，事实依据为固定版项目文档。它不是 DSH 运行成果，也没有真人使用反馈。你可以真实浏览这里的内容和链接，不需要工具接入或下载模型。

## 选一个项目

**我想了解模型：**[打开 DeepSeek-R1 档案](r1.md)。先辨认模型项目提供了什么公开材料，再选择一个关于模型的探究问题。

**我想了解文件协作：**[打开 DSH 档案](dsh.md)。看用途与开始条件，然后[读一份 DSH 入门导览](guide.md)。这条路径是本版已经连接的最小旅程。

不确定选哪个？模型负责生成内容，DSH 这样的智能体框架把模型与工具组织起来。先选你想理解的任务，不是在这里评选谁“更先进”。

## 理解与探究

- 想解释样本与能力：[第四章的小模型练习](../../textbook/chapters/CH04.md)提供手算入口。本示范链接到学习材料，不声称已做过你的实验。
- 想看文字请求怎样变成动作：[第六章的文件任务机制](../../textbook/chapters/CH06.md)解释读取、工具返回与继续行动。

## 可以使用的作品

[DSH 入门导览](guide.md)是一份现在即可阅读的作者作品，说明项目用途、准备条件和一个可尝试的小任务。它不是安装承诺或任务成功报告。读完可回到档案查原文，或去第一章准备材料。

## 改进与协作

本版编辑改动：将原来仅列“项目资料、实践成果”的构想改成按用户目标选择项目；连接了档案、导览与下一步。依据是第七章的产品目标，尚待真实用户验证。发现某句话或入口有问题时，记下位置、依据和期待变化，再进入后续协作实践；这里不伪造读者评论。

维护触发：官方 DSH 使用条件改变时，先重查档案中的接入条件，再检查导览和任务入口是否需要一起修改。当前依据日期：2026-10-29。

## 个人积累：一个可以学走的方法

本示范展示“把来源材料转成使用路径”的方法：先确认对象与版本，按用户任务选内容，再连接档案、作品和下一步，最后走一遍路径。可见证据就是上面的 DSH 档案与导览连接。

你可以用这个方法组织自己的观察站，但它还不是你已掌握能力的证明。换到另一个项目时，重新查对象、来源与使用条件，再用自己的作品和决定说明成长。

## 建自己的观察站

复制[观察站空白模板](../template/README.md)，用已有成果替换提示，从一个对象、一件作品、一条路径开始。五块内容逐步形成，不需要一次建完整网站。回到[第七章](../../textbook/chapters/CH07.md)设计，或去[第八章](../../textbook/chapters/CH08.md)制作。
