如果你想理解“AI 怎样协助整理一份文件”，可以从这里开始。DSH 是工具框架，不是另一个模型名称。

## 项目档案

DeepSeek Harness（DSH）是 DeepSeek 开发的开源智能体框架。它将模型与工具组织起来；本课所据 README 标为开发者预览，提示未来可能有破坏兼容性的变更。

- 事实依据：[固定版中文 README](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/README.zh.md)。对应开头、开发者预览与许可证部分。
- 文档提交：f3803c9（完整提交见来源链接）。核对日期：2026-10-29。不是本课程安装或运行版本。
- README 列出 MIT 许可证，并另有第三方依赖声明。模型服务条件与软件许可需分开查看。

## 开始前，分清阅读与运行

你现在可以直接[阅读入门导览](guide.md)，不需要配置 DSH。若准备实际任务，则先确认服务、可用模型与工作区；本课所据 Web UI 指南从服务已启动开始，需要添加并选中工作区后才能输入任务。

条件依据：[固定版 Web UI 指南](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/docs/user/guide/index.zh.md)。它介绍读取和编辑工作区文件等能力；是否询问审批依权限策略而定。模型接入与费用应按实际教学条件确认。
