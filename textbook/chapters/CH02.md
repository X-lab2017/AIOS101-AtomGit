# 打开一个项目：看见 AI 背后的世界

> 状态：outline
> 版本：0.1.0

一个真实 AI 项目有哪些可以观察的材料？本章将从观察站中的真实问题出发，连接概念解释、动手实践与结果检查。

## 本章学习路线

1. 找到官方项目入口
2. 读懂 README 与模型说明
3. 区分模型、软件、服务与社区
4. 记录版本、来源和未知之处

## 观察站实践

为 DeepSeek 模型与 DSH 建立简明项目档案，提出一个想探究的问题。

完成后留下：有来源和日期的项目档案。实际运行、阅读记录与预设反馈应分别标明。

## 自查与思考

- 我能否用自己的话解释本章的核心问题？
- 我的判断依据是什么，有哪些部分还不能确认？
- 本次观察或修改给作品带来了什么变化？
